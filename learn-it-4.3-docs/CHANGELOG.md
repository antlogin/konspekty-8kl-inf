# CHANGELOG

## Learn-it 4.3 — 2026-10-14

4.3 вводит стандарт навигации по сайту, утверждённый Антоном 14.10.2026. Причина — в каталоге курса тренажёры и другие материалы стояли в одном нумерованном списке с конспектами, со сквозной нумерацией, и ученикам было неочевидно, какой конспект открыть на уроке. Версия 4.2 сохраняется в `Docs/learn-it-docs-4.2-2026-10-12.zip`.

Стандарт утверждён; изменения в `build-catalog.js`, `build-home.js` и `templates/index.html` — следующий этап.

### Каталог курса (новый `03-catalog/NAVIGATION_SPEC.md`)

- Одна строка — один конспект. Тренажёры, анимации, заметки к конспекту — кнопки внутри его строки, без своих номеров.
- Материал относится к конспекту из той же папки или к указанному в `catalog:parent`; остальные попадают в отдельный блок «Общие материалы» без номеров.
- Порядковый номер только у конспекта, без слов «урок» и «занятие»: каталог используется в разных школах с разным расписанием.
- Номер фиксированный: присваивается при первой публикации, хранится в `catalog.json` (`number`), не пересчитывается. Урок без конспекта номера не получает; удалённый номер не переиспользуется.
- Конспекты от новых к старым, верхний (с наибольшим номером) помечен «Последний». Дат и пометки «Сегодня» нет.
- Номер выводится текстом, `<ol>` заменён на `<ul>`; якорь строки `#n-<номер>`.

### Навигация

- В каждом опубликованном HTML-материале строка пути «learn-it.app › курс › номер», её вставляет сборка между маркерами `learn-it:nav`; исходники не меняются. Отключение — `catalog:nav=off`.
- На главной у карточки курса ссылка «Последний: N. Название» на `#n-N` курса.

### Метаданные (`HTML_MATERIAL_SPEC.md`, `CATALOG_SPEC.md`, `MATERIAL_CREATION_GUIDE.md`)

- Новые поля `catalog:number`, `catalog:parent`, `catalog:nav`.
- `catalog:order` и `sites.json → order` больше не задают порядок конспектов, только общих материалов и материалов внутри строки.

### Безопасность публикации и телеметрии (10.10)

- Папки `local*` и `_local*` (например, `_Local-Data`) не синхронизируются, не коммитятся и не публикуются; уже опубликованные копии удаляются из бакета при деплое.
- Листинг бакетов закрыт: файлы читаются публично через флаг `--public-read`, ACL бакета `private`. Деплой проверяет, что сайт открывается, а листинг — нет.
- `GET /api/v1/events` требует ключ учителя (`Authorization: Bearer`), без него 403. Функция и шлюз телеметрии — версия 1.3.0.
- Из репозитория и бакета удалены варианты входного теста по алгебре 11 и ключ для учителя.

### Удаление попыток (09.10)

- `DELETE /api/v1/attempts/{attemptId}` удаляет все события попытки; только с ключом учителя (`TEACHER_TOKEN` в переменных функции).
- Таймаут функции 30 с. Спецификация API Gateway хранится в `telemetry-function/api-gateway.yaml` и обновляется тем же workflow; при неудачной проверке откатываются и функция, и шлюз.

## Learn-it 4.0 — 2026-10-04

4.0 возвращает проекту имя Learn-it и переносит публикацию с Netlify в Yandex Cloud. Причина — у части учеников в России сайты на Netlify открывались плохо или не открывались, особенно не работала отправка файлов. Учебные материалы, каталог класса и контракт телеметрии сохранены из v1.5.

### Публикация

- Каждый класс публикуется в отдельный бакет Yandex Object Storage `<сайт>.learn-it.app` вместо отдельного Netlify-проекта.
- Публикацию выполняет GitHub Actions (`.github/workflows/deploy-yandex.yml` → `scripts/deploy-yandex.sh`) при каждом push в `main`; публикуются только изменённые папки. Ручной запуск публикует всё.
- Новый класс: достаточно записи в `sites.json`, бакет создаётся автоматически. Настраивать Netlify и DNS больше не нужно.
- HTML и JSON отдаются с `Cache-Control: no-cache`, остальные файлы — с кэшем на час.
- `netlify.toml` в папках классов остаётся только до отключения Netlify и в бакеты не публикуется.

### Домен и HTTPS

- Главная страница проекта `https://learn-it.app` — бакет `learn-it.app`.
- `www.learn-it.app` — бакет-перенаправление на `https://learn-it.app`.
- Одна DNS-запись `CNAME * → website.yandexcloud.net` обслуживает все адреса классов, в том числе будущие.
- Один сертификат Let's Encrypt на `learn-it.app` и `*.learn-it.app` в Certificate Manager; продлевается автоматически через запись `_acme-challenge`.

### Главная страница

- Новая главная со ссылками на все классы, сгруппированными по предметам; выбор «Мой класс» запоминается в браузере.
- Собирается `scripts/build-home.js` из `templates/home.html` и `sites.json` в папку `home/`, публикуется в бакет `learn-it.app`.
- Шапка приведена к стандарту страниц классов; сохранён логотип первой версии learn-it.app.

### Результаты учеников

- Netlify Forms полностью выведены из использования. Страницы, которые отправляли файл учителю через Netlify Forms, теперь отправляют событие `result_submitted` в тот же Telemetry API (`cloudSubmit`).
- Содержимое ZIP с одним JSON распаковывается и сохраняется в YDB в читаемом виде; иные файлы передаются в base64.
- Тренажёры физики получили тайм-аут запроса 20 с и видимую отметку «отправлено / не отправлено».
- Локальное сохранение файла ученика остаётся базовым правилом.

### Документация

- Пакет переименован в Learn-it 4.0 и хранится в репозитории: `Docs/learn-it-4.0/`.
- Переписаны: архитектура проекта, публикация, добавление курса, архитектура результатов.
- Добавлены: `03-catalog/HOME_PAGE_SPEC.md`, `06-infrastructure/YANDEX_CLOUD_INFRASTRUCTURE.md`, раздел о `result_submitted` в контракте телеметрии.
