# Learn-it: краткое техническое описание для автора нового курса

Состояние на 18.10.2026, документация Learn-it 4.3. Полные правила лежат в репозитории `antlogin/my-cources-catalog`, папка `Docs/learn-it-4.3/`. Для конспекта главные из них `02-materials/MATERIAL_CREATION_GUIDE.md` и `02-materials/STYLE_GUIDE.md`; при спорном техническом вопросе приоритет у `02-materials/HTML_MATERIAL_SPEC.md`.

## 1. Что такое Learn-it

Learn-it (https://learn-it.app) — набор учебных сайтов одного учителя (Антон) для школьных курсов. На главной собраны карточки всех курсов, у каждого курса свой адрес вида `https://<сайт>.learn-it.app`, например `phys-9-class.learn-it.app`, `alg-11-class.learn-it.app`.

Курс — это каталог учебных HTML-материалов: конспекты занятий, тренажёры, тесты, модели, PDF. Ученики открывают материалы в браузере на компьютере или телефоне, учитель показывает их на экране в классе.

Сейчас есть курсы: физика 7, 8, 9; химия 8, 9; информатика 7, 8, 9, 10, 11 (база и профиль); алгебра 11; SciTime 11; SciModeling; JavaScript «Анимация и игры» (D-Lab).

Контекст школы: школа в Черногории, ученики из разных стран. Примеры не привязываются к России; ориентиры общие, европейские и международные.

## 2. Технологии

- **Материал — один автономный HTML-файл.** CSS и JS встроены в файл, без фреймворков, внешних шрифтов, CDN и математических библиотек. Формулы и дроби верстаются средствами HTML/CSS, графики и схемы — inline SVG, построенный программно.
- **Сборка — Node.js ≥ 18, без зависимостей.** `npm run update` выполняет `sync.js --prune` (копирует материалы из локальных папок учителя в репозиторий по белому списку `.html`, `.pdf`, изображения), `build-catalog.js` (генерирует `catalog.json` и `index.html` каждого курса, вставляет строку пути в материалы) и `build-home.js` (главная).
- **Публикация:** `git push` в `main` → GitHub Actions → Yandex Object Storage (бакет на каждый курс), домен `learn-it.app`, сертификат Let's Encrypt на `*.learn-it.app`. Счётчик Яндекс.Метрики вставляется автоматически при публикации, в исходник его добавлять не нужно.
- **Телеметрия тренажёров:** HTTPS `POST /api/v1/events` → Yandex API Gateway → Cloud Function → YDB. Адрес API:
  `https://d5d3qbcrq94lchv37arh.cmxivbes.apigw.yandexcloud.net/api/v1/events`
- **Исходники материалов** хранятся вне репозитория, в локальных папках учителя (например, `D:\_Work\online-FSH\PHYS-9kl_26-27`); в репозиторий попадают копии.
- Каталог курса — готовый HTML, работает без JavaScript (фильтры — прогрессивное улучшение).

## 3. Как материал попадает в каталог

Каталог читает метаданные из `<head>` каждого HTML-файла.

```html
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<meta name="catalog:title" content="Повторение кинематики. Решение задач">
<meta name="catalog:type" content="lesson">
<meta name="catalog:topic" content="Кинематика. Обобщение">
<meta name="catalog:description" content="Одно-два предложения о содержании.">
<meta name="catalog:tags" content="предмет 9 класс, тема, ключевые слова">
```

- Обязательны только `catalog:title` и `catalog:type`. Типы: `lesson` (конспект), `trainer`, `test`, `game`, `reference`, `lab`, `exam`, `cheatsheet`, `presentation` (список открытый). Конспект в каталоге — только `lesson`, всё остальное становится материалом к нему.
- В `catalog:title` не писать «Занятие N» / «Урок N»: номер конспекта выводит каталог.
- **Одна папка занятия — один конспект** (`lesson`) плюс материалы к нему. Материалы из папки конспекта показываются кнопками в строке этого конспекта и своего номера не получают. Материал вне папки привязывается `catalog:parent="файл_конспекта.html"`, иначе попадает в «Общие материалы».
- Номер конспекта присваивает сборка при первой публикации (1, 2, 3…, новые сверху, верхний помечен «Последний»). Вручную `catalog:number` задаётся только при необходимости.
- Строку пути «learn-it.app › курс › номер» и ссылку в каталог вставляет сборка; вручную не добавлять. Для полноэкранной игры её можно отключить: `catalog:nav=off`.
- `catalog:hidden=true` — файл публикуется по прямой ссылке, но строки в каталоге нет.
- Упрощённая версия для старых браузеров: `material_Legacy.html` с `catalog:hidden=true`, в основном файле `catalog:legacy="material_Legacy.html"` (в каталоге появится значок «HTML | lite»).
- Служебное учителя (ключи, варианты, просмотрщики результатов) — в папках `_Local…` / `Local…` или в файлах `LOCAL_…`: они не синхронизируются и не публикуются.
- Ссылки на материалы другого урока — относительные через его папку (`../Урок_14/trainer.html`). Адреса `*.netlify.app` не использовать.

## 4. Вёрстка и визуальная система

Цвета (переменные CSS):

```css
:root {
  --green: #123d32; --green2: #1d5a49; --paper: #ffffff; --bg: #edf2ee;
  --ink: #14201c; --muted: #61716b; --accent: #ffb000;
  --ok: #238b57; --bad: #c8413a; --line: #d7e0dc;
}
```

Геометрия: на широком экране растут поля, а не интерфейс.

| Ширина окна | Контент | Ориентиры |
|---|---|---|
| > 1400 px | `min(1120px, 100% − 40px)` | h1 ≈ 30 px в шапке |
| 721–1400 px | `min(900px, 100% − 36px)` | текст 14 px, h1 ≈ 24, h2 ≈ 18, кнопки ≈ 34 px |
| ≤ 720 px | одна колонка, поля ≈ 14 px | текст ≥ 16 px, кнопки ≥ 44 px, нет горизонтальной прокрутки |

- Шапка — компактный служебный блок, не hero-экран. Карточки компактные, без декора. Футера нет; блоков «Термины занятия» и «Следующее занятие» нет.
- Основной текст на компьютере в две колонки, на телефоне в одну. Одиночный абзац между блоками — в узкой колонке ≈ 680 px. Крупные блоки по ширине, красная строка 1,5 em, `hyphens: auto`, `<html lang="ru">`; на телефоне по левому краю.
- Парные блоки (определение и формула, термин и пояснение) и задания ставятся рядом в две колонки, на телефоне друг под другом.
- Таблицы не шире ≈ 920 px, графики не шире ≈ 560 px.
- Крупные части занятия (теория, тренировка, практикум) — переключаемые страницы внутри одного файла: короткое меню в шапке и кнопки «Назад» / «Далее». Первый пункт меню конспекта — «План занятия» (уроки в две колонки, «Перемена» одним словом).
- Доступность: zoom не запрещать (`user-scalable=no` и `maximum-scale=1` недопустимы); видимый фокус (`outline: 3px solid var(--accent)`); нативные `radio`/`checkbox`; верно/неверно различается не только цветом; учитывать `prefers-reduced-motion`; при необходимости `@media print`.

## 5. Язык и стиль текста

- Академический, но простой язык хорошего учебника; фразы короткие и полные.
- Пояснения безличны: «Определяется время встречи», а не «Определим…». Без «ты», «мы»-форм, призывов, восклицаний, риторических вопросов. Повелительное наклонение — только в заданиях.
- Термины предмета вместо бытовых слов, без образной лексики. Синоним термина при первом упоминании в скобках, при необходимости с английским.
- Заголовки назывные: «Повторение кинематики. Решение задач», «Модель: фазы Венеры». Повторяющиеся блоки называются одинаково («Вывод», «Цель занятия»).
- Цели занятия — инфинитивом.
- В конце новой темы — задания с раскрывающейся плашкой «Проверить себя» (ответ и короткое решение).
- Типографика: неразрывный пробел между числом и единицей (5 м/с); формула не разрывается переносом; величина курсивом, индекс прямым (`<i>v</i><sub>0x</sub>`), без Юникод-индексов; дроби с горизонтальной чертой на CSS; «ёлочки», длинное тире, буква ё.

## 6. Тренажёры и тесты

- Тренажёр служит запоминанию, а не контролю. Типы: пропуски, порядок строк, сопоставление, пары, ввод команды (проверка без учёта пробелов и регистра).
- Сообщения проверки краткие и нейтральные: «Верно», «Неверно», «Неверно определены: …».
- Правильный вариант не самый длинный, неверные правдоподобны; порядок вариантов перемешивается детерминированно (зерно — id вопроса).
- Вход: поля «Имя» и «Фамилия», серая кнопка «Пройти анонимно».
- Баллы в оцениваемых работах: верная пара = 1 б.; в выборе +1 за верную отметку и −1 за лишнюю (не меньше 0); до 3 проверок, прибавка после 2-й ×0,5, после 3-й ×0,25; правило показывается в блоке «Оценивание».
- Телеметрия: конфигурация `TELEMETRY_CONFIG` с уникальным `trainerId`, `trainerVersion`, `subjectId`, `courseId`; новый `attemptId` на попытку; `seq` с 1 по возрастанию; события `attempt_started`, `answer_changed`, `page_submitted`, `answers_checked`, `attempt_finished` и др.; очередь отправляется пакетами раз в 10 с и удаляется только после ответа `200` с `ok: true`.
- Недоступность API не ломает задание, техническая ошибка не выглядит как учебная. Полный JSON попытки ученик может сохранить локально. Если учителю нужен файл — событие `result_submitted`.
- В HTML/JS нельзя класть секреты (ключи сервисного аккаунта, токены, ключ учителя). Публичный адрес API можно.
- Подробно: `05-telemetry/TRAINER_TELEMETRY_SPEC.md` и `TELEMETRY_INTEGRATION_GUIDE.md`.

## 7. Новый предмет: что нужно для подключения

Это делает учитель в репозитории после того, как материалы готовы; автору конспекта достаточно знать адрес и название курса.

1. Локальная папка исходников курса, по папке на занятие.
2. `target` (имя папки в репозитории, например `8-biology`) и адрес сайта (строчная латиница, цифры, дефис, например `bio-8-class`). Адрес опубликованного курса не меняется.
3. Запись в `sources.local.json` (откуда копировать) и в `sites.json`:
   ```json
   { "target": "8-biology", "title": "Биология · 8 класс", "subtitle": "Учебные материалы", "netlifySite": "bio-8-class" }
   ```
   Предмет на главной берётся из части `title` до « · », класс — из «N класс».
4. `npm run update`, проверка через `npm run dev`, `git push`. Бакет и HTTPS для нового адреса создаются при первой публикации.

## 8. Короткий чек-лист конспекта

```text
[ ] один автономный HTML-файл, charset и viewport, lang="ru"
[ ] catalog:title (без «Занятие N») и catalog:type=lesson, topic, description, tags
[ ] одна папка — один конспект; материалы рядом или с catalog:parent
[ ] без ручной ссылки «в каталог» и без счётчика Метрики
[ ] ширина 1120 / 900 px, на телефоне одна колонка без горизонтальной прокрутки
[ ] текст в две колонки, по ширине, красная строка; таблицы ≤ 920 px, графики ≤ 560 px
[ ] меню: «План занятия» первым, части — переключаемые страницы
[ ] безличный академический язык, назывные заголовки, нет примеров про Россию
[ ] неразрывные пробелы, индексы прямые, дроби на CSS, «ёлочки», ё
[ ] «Проверить себя» в конце темы; без футера
[ ] zoom разрешён, фокус видим, reduced-motion учтён
[ ] для тренажёра: телеметрия по спецификации, без секретов, работает без API
```

Пример готового конспекта по этим правилам: физика 9 класс, занятие 4 (`9-physics/Fizika_9_klass_zanyatie_4.html` в репозитории).
