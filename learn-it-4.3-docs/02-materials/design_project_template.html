Обзор дизайн-системы

Основной принцип

На компьютере содержимое занимает не более 80% ширины окна, поэтому слева и справа всегда остаётся не менее 10% свободного пространства.

Ключевые признаки

адаптивность масштабирование мобильный дизайн единая палитра доступный focus
desktop: ≤ 1120px · compact: ≤ 900px · mobile: около 14px боковых полей

Пример учебного содержания

Основной блок

Основной текст набран системным шрифтом с размером около 16 px и увеличенным межстрочным интервалом для комфортного чтения.

Второстепенные комментарии и пояснения используют приглушённый цвет.

Визуальная иерархия

Заголовки используют тёмно-зелёную гамму. Жёлтый цвет применяется только как акцент: для важных действий, выбора и прогресса.

Компоненты и состояния

Карточки

Белые поверхности отделяются от светлого фона тонкой границей и умеренной тенью. Скругления — мягкие, без декоративной избыточности.

Состояния

Выбор обозначается жёлтым, успех — зелёным, ошибка — красным. Эти состояния не смешиваются между собой.

Верно — состояние успешного действия
Ошибка — состояние неверного действия
