# Стандарт навигации по сайту

**Версия пакета:** Learn-it 4.3  
**Статус:** утверждённый стандарт, реализация в скриптах — следующий этап

## 1. Зачем

В каталоге курса конспекты и сопутствующие материалы (тренажёры, анимации, заметки) лежали одним нумерованным списком со сквозной нумерацией. Тренажёр занимал номер между конспектами, номер в каталоге не совпадал с тем, что ученик ожидал, а самый новый материал оказывался внизу. Ученикам было неочевидно, какой конспект открыть на текущем уроке.

Стандарт задаёт:

- структуру каталога одного курса (раздел 3);
- нумерацию конспектов (раздел 4);
- единую навигацию между главной, курсом и материалом (раздел 6).

## 2. Термины

| Термин | Значение |
|---|---|
| Конспект | основной материал занятия, `catalog:type=lesson` |
| Материал к конспекту | любой другой материал, относящийся к конкретному конспекту: тренажёр, анимация, заметка, тест, PDF и т. п. |
| Общий материал | материал, не привязанный к конкретному конспекту (справочник, тренажёр на весь курс) |
| Порядковый номер | постоянный номер конспекта в каталоге курса |

Слова «урок» и «занятие» в номере не используются. Один каталог курса может использоваться в разных школах с разным расписанием, поэтому номер — это порядковый номер конспекта в курсе, а не номер урока по расписанию.

## 3. Структура каталога курса

### 3.1. Одна строка — один конспект

Каталог курса — это список конспектов. Каждая строка (карточка конспекта) содержит:

```text
[7]  Единичная окружность. Синус и косинус        ← название конспекта, главная ссылка
     Тема · описание
     [Тренажёр: Тригонометрическая окружность] [Анимация: …]   ← материалы к конспекту
     HTML | lite                                   ← Legacy, если есть
```

- Главная ссылка строки ведёт на конспект.
- Материалы к конспекту показываются небольшими кнопками-ссылками внутри строки конспекта. На кнопке — тип материала и его название.
- Материалы к конспекту **не получают** собственного номера и отдельной строки.
- Дат в каталоге нет.

### 3.2. Порядок

- Конспекты идут **от новых к старым**: самый новый сверху.
- Внутри строки материалы к конспекту идут в порядке добавления.

### 3.3. Последний конспект

- Верхняя строка (конспект с наибольшим номером) выделяется рамкой и пометкой **«Последний»**.
- Слово «Сегодня» не используется: последний конспект мог быть опубликован неделю назад.
- Отдельный закреплённый блок над списком не нужен: последний конспект и так стоит первым.

### 3.4. Общие материалы

- Общие материалы выводятся отдельным блоком **«Общие материалы»** под списком конспектов.
- В блоке нет номеров; порядок — порядок добавления (или `sites.json → order`, см. раздел 5.4).
- Если общих материалов нет, блок не выводится.

### 3.5. Как материал попадает к конспекту

Принадлежность определяется в таком порядке:

```text
1. catalog:parent в материале — явная ссылка на файл конспекта
2. папка: материал лежит в одной папке с конспектом
3. иначе — общий материал
```

Правило папки:

- одна папка занятия = один конспект (`catalog:type=lesson`, не скрытый) + его материалы;
- если в папке нет конспекта или в ней несколько конспектов, автоматической привязки нет: материалы становятся общими, а генератор выводит предупреждение (кроме материалов с `catalog:parent`);
- материалы в корне курса (как в `8-physics`, `9-physics`) привязываются к конспекту только через `catalog:parent`.

`catalog:parent` задаётся путём относительно самого материала:

```html
<meta name="catalog:parent" content="algebra_11_unit_circle_lesson.html">
```

Пустое значение `catalog:parent=""` в папке занятия делает материал общим, даже если рядом лежит конспект.

PDF и изображения метаданных не имеют; к конспекту они привязываются по правилу папки.

## 4. Порядковый номер конспекта

### 4.1. Правила

- Номер получает только конспект (`catalog:type=lesson`, не скрытый).
- Номера идут подряд: 1, 2, 3… без пропусков. Урок, для которого не было конспекта, номера не получает.
- Сдвоенный урок с одним конспектом — один номер.
- Номер **фиксированный**: присваивается конспекту один раз, при первой публикации, и больше не меняется. Новый конспект получает номер на единицу больше максимального.
- Верхний (новый) конспект имеет самый большой номер: нумерация растёт снизу вверх.
- Номер выводится как явный текст в строке («7»), а не автоматической нумерацией `<ol>`. Автоматическая нумерация списка привязывает номер к месту в списке, а не к конспекту.

### 4.2. Где хранится

Номер хранится в `catalog.json` курса в поле `number` и при повторных сборках берётся оттуда, как сейчас `addedAt`.

Явно задать номер можно метаданными конспекта:

```html
<meta name="catalog:number" content="7">
```

`catalog:number` имеет приоритет над сохранённым значением. Генератор останавливается с ошибкой, если два конспекта курса получили одинаковый номер.

### 4.3. Конспект, дописанный задним числом

Если конспект к уже прошедшему занятию появился позже следующих, предпочтительный способ — добавить его как материал к соседнему конспекту (`catalog:type` не `lesson` или `catalog:parent`). Номера остальных конспектов при этом не меняются.

Если он обязательно нужен отдельной строкой, ему задаётся промежуточный номер вида `7а` через `catalog:number`. Такая строка стоит между конспектами 8 и 7.

### 4.4. Удаление конспекта

Номер удалённого конспекта не переиспользуется. В нумерации остаётся пропуск — это допустимо и лучше, чем сдвиг номеров у остальных.

## 5. Изменения в генерации каталога

### 5.1. `catalog.json`

Каждая запись дополняется полями:

```json
{
  "number": 7,
  "parent": "Урок_14_0210/algebra_11_unit_circle_lesson.html",
  "role": "attached"
}
```

| Поле | Значение |
|---|---|
| `number` | порядковый номер конспекта; `null` у материалов |
| `parent` | файл конспекта, к которому относится материал; `null` у конспекта и общего материала |
| `role` | `lesson`, `attached` или `general` |

Главная страница по-прежнему считает материалы по длине `catalog.json`.

### 5.2. Статический `index.html`

Требования [CATALOG_SPEC.md](CATALOG_SPEC.md) сохраняются: вся структура видна без JavaScript, все переходы — обычные `<a href>`.

Разметка (ориентир):

```html
<ul class="catalog-list">
  <li class="catalog-item catalog-item--latest" id="n-7">
    <p class="catalog-meta"><span class="catalog-num">7</span> · Последний</p>
    <h2 class="catalog-title"><a href="…">Название конспекта</a></h2>
    <p class="catalog-desc">…</p>
    <p class="catalog-extras">
      <a class="catalog-extra" href="…">Тренажёр: …</a>
    </p>
  </li>
  …
</ul>

<section class="catalog-general">
  <h2>Общие материалы</h2>
  <ul>…</ul>
</section>
```

- У каждой строки конспекта якорь `id="n-<номер>"`, например `#n-7`.
- `<ol>` заменяется на `<ul>`: номер выводится текстом.

### 5.3. Поиск и фильтры

- Поиск ищет по конспектам и по материалам к ним; строка конспекта показывается, если совпал сам конспект или любой его материал.
- Фильтр по типу оставляет строки, где есть материал выбранного типа, и выделяет этот материал.
- Без JavaScript фильтры скрыты, как и раньше.

### 5.4. `sites.json → order` и `catalog:order`

- Для конспектов порядок задаётся только номером; `order` и `catalog:order` на них не действуют.
- `order` и `catalog:order` продолжают задавать порядок общих материалов и материалов внутри строки конспекта.

## 6. Навигация по сайту

### 6.1. Уровни

```text
learn-it.app                 главная: все курсы
  └ <сайт>.learn-it.app/     курс: конспекты и общие материалы
      └ конспект / материал  страница материала
```

Адрес конспекта в каталоге постоянный: `https://<сайт>.learn-it.app/#n-<номер>`.

### 6.2. Строка пути в материале

Каждая опубликованная HTML-страница материала получает вверху тонкую строку пути:

```text
learn-it.app › Алгебра · 11 класс › 7
learn-it.app › Алгебра · 11 класс › 7 › Тренажёр
learn-it.app › Алгебра · 11 класс › Общие материалы
```

- `learn-it.app` → `https://learn-it.app/`;
- название курса (`title` из `sites.json`) → корень курса (`index.html`, относительной ссылкой);
- номер → корень курса с якорем `#n-<номер>`;
- последний элемент — текущая страница, без ссылки.

Требования:

- обычные `<a href>`, без JavaScript, без внешних ресурсов;
- одна строка высотой не больше ~28 px, шрифт ~12 px, цвета шапки каталога (`#123d32` / `#cfe0da`); на узком экране длинное название курса сокращается многоточием, горизонтальной прокрутки нет;
- в `@media print` строка скрывается;
- строку не нужно добавлять в исходники вручную: её вставляет сборка при копировании в репозиторий (см. 6.4).

### 6.3. Каталог курса

- В шапке каталога слева логотип learn-it со ссылкой на главную (как на главной странице).
- Под шапкой — список конспектов (раздел 3), ниже — общие материалы.

### 6.4. Вставка строки пути сборкой

- Строку вставляет `build-catalog.js` в опубликованные копии HTML сразу после `<body>`, внутри маркеров:

```html
<!-- learn-it:nav:start -->
…
<!-- learn-it:nav:end -->
```

- При повторной сборке содержимое между маркерами заменяется, а не дублируется.
- Исходные файлы в рабочих папках не меняются.
- Legacy-версии получают ту же строку.
- Материал может отказаться от строки: `<meta name="catalog:nav" content="off">` (например, полноэкранная анимация или игра). Тогда ссылку «в каталог» при необходимости делает автор материала.
- Строка не должна ломать sticky-навигацию и переключаемые части занятия: она не фиксируется и прокручивается вместе со страницей.

### 6.5. Главная страница

- У карточки курса, кроме ссылки на курс, есть ссылка **«Последний: 7. Название»**, которая ведёт на `/#n-7` курса.
- Метка «Новое» сохраняется по прежнему правилу (см. [HOME_PAGE_SPEC.md](HOME_PAGE_SPEC.md)).

## 7. Переход существующих курсов

1. Номера присваиваются конспектам существующих курсов один раз, в текущем порядке каталога (от старых к новым): 1, 2, 3…
2. Материалы к конспектам определяются правилом папки; для курсов без папок (`8-physics`, `9-physics`) нужные материалы получают `catalog:parent`.
3. Legacy-копии конспектов, которые сейчас попадают в каталог отдельными строками (например, `9-chemistry/week-03/…_legacy.html`), помечаются `catalog:hidden=true` и подключаются через `catalog:legacy`.
4. После первой сборки номера фиксируются в `catalog.json`.

Пример для `11-algebra` (было → стало):

```text
было: 12 строк, тренажёры под номерами 8 и 10
стало: 10 конспектов (1–10), тренажёры — кнопки в строках 7 и 8
```

## 8. Контрольный список

```text
[ ] номер есть только у конспектов
[ ] номера фиксированы в catalog.json и не меняются при новых публикациях
[ ] конспекты от новых к старым, верхний помечен «Последний»
[ ] дат в каталоге нет
[ ] материалы к конспекту — кнопки внутри его строки, без номеров
[ ] общие материалы — отдельный блок без номеров
[ ] у строки конспекта якорь #n-<номер>
[ ] в каждом материале есть строка пути (кроме catalog:nav=off)
[ ] всё работает без JavaScript
```
