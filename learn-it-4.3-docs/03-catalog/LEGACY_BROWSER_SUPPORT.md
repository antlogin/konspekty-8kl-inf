# Поддержка Legacy-версий материалов

**Версия пакета:** Learn-it 4.3  
**Статус:** поддержка каталога реализована

## 1. Определение

Legacy-версия — техническая альтернатива актуального учебного материала для максимально широкой совместимости со старыми браузерами, включая старые Safari/WebKit.

Legacy не означает устаревшее содержание. По возможности современная и Legacy-версии содержат один и тот же учебный материал.

## 2. Модель

```text
основной материал
    ├── единственная строка каталога
    └── необязательная ссылка HTML | lite

Legacy-файл
    ├── публикуется
    ├── доступен по прямой ссылке
    └── скрыт как самостоятельная запись
```

## 3. Именование

Для новых материалов рекомендуется:

```text
<name>.html
<name>_Legacy.html
```

Например:

```text
Fizika_9_klass_zanyatie_3.html
Fizika_9_klass_zanyatie_3_Legacy.html
```

Старые варианты суффиксов вроде `_ios11` или `_yandex` не следует использовать как новую общую схему: Legacy описывает класс совместимости, а штатная телеметрия является функцией современной основной версии.

## 4. Размещение

Предпочтительно хранить основной и Legacy-файл рядом. Допустим и безопасный относительный путь в подпапку, если это удобно структуре курса.

Не допускаются:

- абсолютный URL в `catalog:legacy`;
- выход выше корня курса через `../`;
- ссылка на несуществующий файл.

## 5. Метаданные основного файла

```html
<meta name="catalog:title" content="Название">
<meta name="catalog:type" content="lesson">
<meta name="catalog:legacy" content="material_Legacy.html">
```

Если Legacy нет, `catalog:legacy` можно не указывать или оставить пустым.

## 6. Метаданные Legacy-файла

```html
<meta name="catalog:hidden" content="true">
```

Это универсальный механизм «опубликовано, но без отдельной строки каталога».

Папка или суффикс имени сами по себе не являются механизмом скрытия.

## 7. Поведение генератора

Перед созданием ссылки `build-catalog.js` проверяет:

1. относительность пути;
2. отсутствие опасного выхода выше корня;
3. наличие файла.

При ошибке основной материал остаётся в каталоге, а Legacy-ссылка не создаётся.

## 8. Отображение

Текущая маркировка:

```text
HTML | lite
```

SVG имеет размер `78 × 18 px`, но SVG — только визуальный слой.

Ссылка должна оставаться обычным `<a href>` и иметь:

```text
title / aria-label: Версия для старых браузеров
fallback: HTML lite
```

## 9. Требования к самой Legacy-странице

Legacy-страница должна проектироваться консервативно:

- не требовать современных JS API для базовой учебной механики;
- избегать синтаксиса JavaScript, который не парсится целевым старым браузером;
- не делать CSS Grid, современные custom properties или другие новые CSS-возможности единственной основой критической компоновки, если целевой браузер их не поддерживает;
- иметь обычные HTML-ссылки и формы;
- сохранять читаемый fallback при отключённом или частично работающем JavaScript;
- не запрещать zoom;
- по возможности сохранять содержание, ответы и учебную логику современной версии.

Конкретный уровень упрощения зависит от браузера, ради которого создаётся копия. Если современная функциональность не может быть воспроизведена, отличие должно быть осознанным и минимальным.

## 10. Телеметрия и Legacy

Legacy-страница не обязана реализовывать современную Telemetry API-интеграцию, если используемый старый браузер не поддерживает необходимый транспорт/JS. Это не должно препятствовать открытию учебного материала.

Современная основная версия, напротив, может включать штатную телеметрию без суффикса в имени файла.

## 11. Проверка перед публикацией

```text
[ ] имя соответствует *_Legacy.html либо принят безопасный относительный путь
[ ] основной файл содержит catalog:legacy
[ ] Legacy содержит catalog:hidden=true
[ ] Legacy-файл попадает в whitelist синхронизации
[ ] npm run update не выдаёт предупреждение по этой ссылке
[ ] в index.html только одна строка основного материала
[ ] рядом отображается HTML | lite
[ ] ссылка реально открывается
[ ] основное содержание совпадает с современной версией
[ ] страница проверена в целевом старом браузере или максимально близкой среде
```
