# Главная страница learn-it.app

**Версия пакета:** Learn-it 4.3  
**Статус:** реализована

## 1. Назначение

`https://learn-it.app` — точка входа для учеников: ссылки на сайты всех классов, сгруппированные по предметам. Материалов самих по себе главная не содержит.

## 2. Файлы

```text
templates/home.html     шаблон (ручной источник)
scripts/build-home.js   генератор
sites.json              список курсов
<course>/catalog.json   число материалов и даты добавления
home/index.html         результат (генерируется, вручную не править)
```

Сборка:

```powershell
npm run home      # только главная
npm run update    # всё, включая главную
```

Публикация: папка `home/` → бакет `learn-it.app` (см. [PUBLISHING_WORKFLOW.md](../04-publishing/PUBLISHING_WORKFLOW.md)).

## 3. Как курс попадает на главную

Для каждой записи `sites.json` без `"hidden": true`:

| Что | Откуда |
|---|---|
| Предмет | часть `title` до « · » |
| Номер класса | «N класс» в `title` |
| Вариант группы | третья часть `title` после второго « · », дописывается в заголовок карточки: «Информатика · 11 класс · профиль» → «Информатика, 11 класс, профиль» |
| Адрес | `host`, иначе `<subdomain или netlifySite>.learn-it.app` |
| Число материалов | длина `<target>/catalog.json` |
| Метка «Новое: дата» | самое позднее `addedAt` в `catalog.json`, если оно не старше 7 дней |

Разделы и их порядок:

```text
Физика → Информатика → Химия → Математика (Алгебра, Геометрия) → Дополнительные курсы
```

В «Дополнительные курсы» попадают курсы без номера класса и предметы вне списка (SciTime, JavaScript). Подпись на плашке для них задаётся в `BADGE_TEXT` в `build-home.js`. Внутри раздела курсы сортируются по номеру класса.

Новый предмет с номером класса, которого нет в списке разделов, попадёт в «Дополнительные курсы», пока раздел не добавлен в `SECTIONS` в `build-home.js`.

## 4. Оформление

Главная следует визуальной системе страниц классов (`templates/index.html`):

- фон `#edf2ee`, текст `#14201c`, шрифт Arial/Helvetica, базовый размер 15 px;
- рабочая ширина до 1120 px, поля 20 px (на телефоне 14 px);
- фокус — жёлтая обводка `#ffb000`.

### Шапка

- фон `#123d32`, нижняя граница 1 px `#0d3027`, компактная высота как у страниц классов;
- слева логотип первой версии learn-it.app: надпись **learn-it** (25 px, жирная) в скруглённой плашке `#184a3d` и под ней полоска прогресса, заполненная на 52 % жёлтым `#ffb000`; логотип — ссылка на главную;
- справа от логотипа девиз в две строки, по центру, 13 px, цвет `#cfe0da`:
  «Конспекты уроков и интерактивные тренажёры.» / «Выберите свой предмет и класс.»;
- до 720 px: логотип 22 px, девиз 12 px;
- до 480 px: логотип сверху по центру, девиз под ним, каждая строка девиза целиком.

### Выбор класса

- под шапкой строка «Мой класс: Все 7 8 9 11», оформленная как фильтры страниц классов (белые кнопки, активная — жёлтая);
- выбор сохраняется в `localStorage` (`learnit-grade`);
- без JavaScript строка скрыта и видны все курсы.

### Карточки

- четыре в ряд шире 1400 px, три от 901 до 1400 px, две от 721 до 900 px, одна на телефоне;
- плашка с номером класса (или коротким именем курса), название, число материалов, метка «Новое», адрес сайта (на телефоне скрыт);
- ссылка «Последний: 7. Название» на последний конспект курса — ведёт на `<сайт>.learn-it.app/#n-7` (номер и название берутся из `catalog.json`, см. [NAVIGATION_SPEC.md](NAVIGATION_SPEC.md), 6.5); у курса без конспектов ссылки нет.

Значок вкладки — три жёлтых столбика на зелёном фоне (встроенный SVG).

## 5. Совместимость

Те же правила, что у каталога класса ([CATALOG_SPEC.md](CATALOG_SPEC.md), разделы 8, 9, 16):

- все ссылки на курсы — обычные `<a href>`, видны без JavaScript;
- JavaScript только для выбора класса и написан без современных обязательных возможностей;
- внешних шрифтов, CDN и запросов нет.

## 6. www и старая версия

`https://www.learn-it.app` перенаправляется на `https://learn-it.app` (бакет-перенаправление). Первая версия сайта learn-it.app на Netlify больше не обслуживается.
