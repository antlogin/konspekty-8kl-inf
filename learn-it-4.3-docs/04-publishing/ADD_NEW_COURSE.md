# Полный цикл добавления нового курса

**Версия пакета:** Learn-it 4.3

В 4.0 новый курс не требует настройки хостинга и DNS: бакет создаётся при первой публикации, адрес `<сайт>.learn-it.app` начинает работать сразу (запись `*` в DNS и сертификат `*.learn-it.app` уже покрывают его), карточка курса появляется на главной.

## 1. Создать локальную source-папку

Например:

```text
D:\_Work\online-FSH\PHYS-8kl_26-27
```

Исходные учебные материалы хранить вне общего Git-репозитория.

## 2. Выбрать target и адрес

```text
target:  8-physics
адрес:   phys-8-class.learn-it.app
```

Адрес задаётся полем `netlifySite` (историческое имя поля) или, если нужен другой, полем `subdomain`. Допустимы строчные латинские буквы, цифры и дефис. Адрес однажды опубликованного курса не менять: у учеников останутся старые ссылки, а старый бакет придётся удалять вручную.

## 3. Добавить mapping в `sources.local.json`

```json
{
  "source": "D:/_Work/online-FSH/PHYS-8kl_26-27",
  "target": "8-physics"
}
```

Если файл содержит массив mappings, добавить запись в существующую структуру.

## 4. Зарегистрировать курс в `sites.json`

Добавить запись по той же схеме, что у существующих курсов:

```json
{
  "target": "8-physics",
  "title": "Физика · 8 класс",
  "subtitle": "Учебные материалы",
  "netlifySite": "phys-8-class"
}
```

`title` используется и на странице класса, и на главной: предмет берётся из части до « · », номер класса — из «N класс». Курсы без номера класса попадают в раздел «Дополнительные курсы».

Если в одном классе два курса по одному предмету (например, базовая и профильная группы), различие пишется третьей частью `title`; на главной оно добавится к заголовку карточки:

```json
{
  "target": "11-informatics-pro",
  "title": "Информатика · 11 класс · профиль",
  "subtitle": "Учебные материалы профильной группы",
  "netlifySite": "inf-11-pro"
}
```

Подробности — [HOME_PAGE_SPEC.md](../03-catalog/HOME_PAGE_SPEC.md).

```text
sources.local.json → откуда копировать
sites.json         → какие курсы строить, публиковать и показывать на главной
```

## 5. Запустить обновление

```powershell
cd D:\_Misc\_PetProjects\My-cources-catalog
npm run update
```

Ожидается:

- target создан/обновлён, применён whitelist;
- `catalog.json` и `index.html` курса созданы;
- в `home/index.html` появилась карточка курса.

## 6. Проверить локально

```powershell
npm run dev
```

```text
[ ] index.html курса открывается
[ ] материалы перечислены, ссылки работают
[ ] вложенные папки работают
[ ] порядок и заголовки верны
[ ] каталог читаем без JavaScript
[ ] фильтры работают с JavaScript
[ ] Legacy-ссылки работают, если есть
[ ] карточка курса есть на главной, в нужном разделе
```

## 7. Commit и push

```powershell
git status
git add .
git status
git commit -m "Add 8th grade physics course"
git push
```

Убедиться, что `sources.local.json` не попадает в commit.

## 8. Проверить публикацию

Изменение `sites.json` публикует все сайты и главную.

1. GitHub → **Actions** → запуск **Deploy to Yandex Cloud** должен быть зелёным; в журнале — строка `Создаю бакет phys-8-class.learn-it.app` и `HTTPS: сертификат привязан`.
2. Открыть `https://phys-8-class.learn-it.app`.
3. Открыть `https://learn-it.app` и проверить карточку.

Если адрес открывается с ошибкой сертификата сразу после первой публикации — подождать до получаса: привязка сертификата к новому бакету применяется с задержкой.
