## Конспект К1: содержание

Тема — §3.1 Босовой: понятие алгоритма, исполнитель (среда, система команд, режимы работы), свойства алгоритмов (дискретность, понятность, определённость, результативность, массовость). Части и тайминг — по таблице 1.1 спецификации (план занятия, повторение, теория, разбор кода, практикум, итог). Для К1 «Повторение» — вопросы на житейское понимание алгоритма. Python в К1 появляется как первая запись алгоритма для исполнителя-компьютера: простые программы с `print()`, без опоры на темы следующих конспектов (переменные и `input()` — К4–К5). Задачи практикума должны быть посильны тем, кто программирует впервые. Примеры без привязки к России (школа в Черногории).

## Google Apps Script

По разделам 2.2, 2.4 и 2.6 спецификации. Один `doPost` (`Content-Type: text/plain`, без preflight), четыре действия:

- **проверка кодового слова** группы: слова и соответствие группам (Компас ср, Компас пт, ФШ пн) — в свойствах скрипта, не в HTML; при верном слове возвращается группа;
- **приём пакетов телеметрии**, которые конспект отправляет раз в 30 с (и сразу при проверке задачи, завершении, `pagehide`, восстановлении связи, очереди ≥ 25); без дублей по ключу `(attemptId, seq)`; ответ `{ok: true}`;
- **сохранение снимка** состояния и **выдача последнего снимка** для восстановления (одна строка на ученика и урок);
- **таблицы на Диске** создаются автоматически: отдельная таблица на каждую пару «группа + урок» (листы «События», «Попытки», «Сводка», «Снимки», «Сданные работы») и «Журнал курса» по каждой группе (строка на ученика, столбец на конспект). Курс и урок приходят в каждом запросе, чтобы скрипт подходил и другим курсам. Учесть лимит одновременных выполнений (LockService, короткие операции).

## Решения по умолчанию

- Если скрипт недоступен, ученик всё равно допускается к работе с пометкой «группа не проверена»; это пишется в журнал (`access_checked`).
- «Пройти анонимно» пропускает только ввод имени и фамилии; кодовое слово обязательно и для анонимного входа.
- Адрес курса (`*.learn-it.app`), адрес веб-приложения скрипта в `TELEMETRY_CONFIG` и кодовые слова — **заглушки**, явно помеченные (например, `REPLACE_ME`). Учитель заменит их сам; в методичке и README скрипта перечислить, что и где заменить.

## Проверка перед сдачей

- Конспект открывается в Chromium без сети и без ошибок в консоли; в нём нет обращений к внешним адресам, кроме адресов телеметрии из конфигурации.
- Каждая задача практикума решается эталонным решением из методички и не засчитывается типичным неверным решением.
- Работают `input()` (если используется), turtle (если используется), пояснения ошибок, остановка бесконечного цикла.
- Восстановление после перезагрузки страницы из памяти браузера работает; очередь телеметрии при недоступном сервере не теряется.
- Вёрстка проверена на ширине 1440, 1024 и 390 px и в режиме печати.
- `Code.gs` проходит синтаксическую проверку (например, `node --check` на копии с расширением `.js`).
