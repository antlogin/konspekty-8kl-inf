Планируемый результат. Называются среда и команды исполнителя «Черепаха»; по рисунку определяется последовательность команд; составляются линейные программы, рисующие углы, квадрат, прямоугольник и треугольник; используются команды управления пером, цветом и координатами.

Теория

Шаг 1. Исполнитель «Черепаха»

Исполнитель «Черепаха» (англ. turtle) — виртуальный исполнитель, который перемещается по плоскости и оставляет за собой след. Он применяется для построения рисунков по программе; идея исполнителя восходит к учебному языку программирования Logo.

Среда исполнителя — плоскость с системой координат. Начало координат (0; 0) находится в центре поля, ось x направлена вправо, ось y — вверх. В начале работы черепаха находится в начале координат и направлена вправо. Расстояния измеряются в шагах, углы — в градусах.

Чтобы использовать исполнителя в Python, программа начинается командой import turtle: она подключает модуль (англ. module) — готовый набор команд. Команды записываются в виде turtle.команда(параметры). Исполнитель работает в режиме программного управления: выполняется вся программа сверху вниз.

КомандаДействие
turtle.forward(n)переместиться вперёд на n шагов
turtle.backward(n)переместиться назад на n шагов
turtle.left(a)повернуть налево (против часовой стрелки) на a градусов
turtle.right(a)повернуть направо (по часовой стрелке) на a градусов
turtle.penup(), turtle.pendown()поднять перо (перемещение без следа) и опустить перо
turtle.pencolor("red")задать цвет линии: "red", "blue", "green", "black"
turtle.pensize(n)задать толщину линии
turtle.goto(x, y)переместиться в точку с координатами (x; y)

Блок-схема

Программа на Python

import turtle
turtle.forward(100)
turtle.left(90)
turtle.forward(50)

Действия исполнителя обозначаются в блок-схеме прямоугольниками (процесс).

Рисунок

Шаг 2. Линейный алгоритм: рисование фигур

Линейный алгоритм (следование) — последовательность команд, которые выполняются одна за другой в порядке записи, каждая один раз. Программы для черепахи в этом конспекте линейные: команды повторяются записью подряд (циклы изучаются в следующих конспектах).

Фигура строится из отрезков; между отрезками черепаха поворачивается. Для квадрата со стороной 100 дважды записываются два действия: «вперёд на 100» и «налево на 90» — всего четыре стороны и четыре поворота.

Угол поворота на вершине равен внешнему углу фигуры, то есть 180° минус внутренний угол. У квадрата внутренний угол 90°, поэтому поворот равен 90°; у равностороннего треугольника внутренний угол 60°, поэтому поворот равен 120°.

Блок-схема

Программа на Python

import turtle
turtle.forward(100)
turtle.left(90)
turtle.forward(100)
turtle.left(90)
turtle.forward(100)
turtle.left(90)
turtle.forward(100)
turtle.left(90)

Рисунок

Шаг 3. Перо, цвет и координаты

Перо — часть исполнителя, которая оставляет след. Пока перо опущено (pendown), перемещение рисует линию. Команда penup() поднимает перо: черепаха перемещается без следа, пока перо снова не опущено командой pendown().

Цвет и толщина линии задаются командами pencolor("red") и pensize(3). Они действуют на все следующие линии, пока не заданы новые значения. Название цвета записывается в кавычках на английском языке.

Команда goto(x, y) перемещает черепаху в точку с заданными координатами. Если перо опущено, до новой точки проводится линия; направление черепахи при этом не меняется. Для перемещения без следа перед goto записывается penup().

Блок-схема

Программа на Python

import turtle
turtle.pencolor("green")
turtle.forward(40)
turtle.penup()
turtle.forward(20)
turtle.pendown()
turtle.forward(40)
