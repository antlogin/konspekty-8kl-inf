## 3. Ход урока

**Повторение.** Задание «Время прибытия»: 22 · 60 + 50 + 95 = 1465 — больше 1440 минут в сутках. Проговорить, что `% 1440` отбрасывает полные сутки так же, как `% 60` отбрасывает полные часы. Засчитывается и вариант `t // 60 % 24` в выводе.

**Шаг 1. Условие и сравнения.** Связь с главой 2: высказывание истинно или ложно. Показать в песочнице `print(7 > 3)` → `True`. Отдельно на доске: `=` и `==`. Тип `bool` и логические операции `and`, `or`, `not` не вводятся — это урок 9.

**Шаг 2. Полная форма.** Нарисовать ромб с выходами «да» (слева) и «нет» (справа), как в учебнике. На алгоритмическом языке: если … то … иначе … все. В Python: двоеточие, отступ 4 пробела, `else` под `if`. Редактор сам ставит отступ после строки с двоеточием; Перед `else` отступ требуется убрать: клавиши Shift+Tab (или четыре раза Backspace) — показать это классу, иначе `else` окажется внутри ветви. В песочнице ввести 0: ноль чётный.

**Шаг 3. Большее из двух.** Трассировка трёх случаев (5 и 12, 12 и 5, 7 и 7). Вывод после ветвления — одна команда для обеих ветвей. В песочнице удалить отступ и прочитать сообщение IndentationError. Функции `max()` и `min()` не используются: в задаче 2 `min()` запрещён правилом проверки.

**Разбор кода.** Задание 1: для 12 условие `12 < 12` ложно — взрослый билет; строка 7 выводится всегда (типичный неверный ответ — вариант без «Билет оформлен» или с обеими ветвями). Задание 2: `age <= 14` или `age < 15` (ошибка — `age < 14`). Задание 3: `charge > 20` → `charge < 20` (ошибка — `<= 20`: при 20 % выводится «Требуется зарядка»).

**Практикум.** Темп: задача 1 — 3 мин, 2 — 3, 3 — 4, ★ — по готовности, ★★ — для сильных. Все задачи проверяются на нескольких наборах, часть скрыта.

# 4★. Конфеты поровну (первая строка вывода — до ветвления)
n = int(input())
k = int(input())
print("Каждому:", n // k)

```python
# 5★. Время в пути (ветвление обязательно; (t2 - t1) % 1440 без if не засчитывается правилом)
h1 = int(input())
m1 = int(input())
h2 = int(input())
m2 = int(input())
t1 = h1 * 60 + m1
t2 = h2 * 60 + m2
if t2 > t1:
    d = t2 - t1
else:
    d = t2 - t1 + 1440
print("В пути:", d // 60, "ч", d % 60, "мин")
```

```python
# 6★★. Счастливый билет (012210 вводится с нулём, int() его принимает)
n = int(input())
a = n // 1000
b = n % 1000
s1 = a // 100 + a // 10 % 10 + a % 10
s2 = b // 100 + b // 10 % 10 + b % 10
if s1 == s2:
    print("Счастливый")
else:
    print("Обычный")
```

```python
# 7★★. Ближайший автобус; засчитывается и w = (k - t % k) % k без ветвления
k = int(input())
h = int(input())
m = int(input())
t = h * 60 + m
if t % k == 0:
    w = 0
else:
    w = k - t % k
print("Ожидание:", w, "мин")
```

**Проверить себя:** 1 — `3`; 2 — `n % 2 == 1`; 3 — в строке 2 `=` вместо `==`.

## 5. Типичные ошибки

| Ошибка | Что видит ученик | Что ответить |
|---|---|---|
| `=` в условии | SyntaxError; подсказка про `==` | `=` — присваивание, сравнение — `==` |
| Нет двоеточия после условия или `else` | SyntaxError «в конце строки с if отсутствует двоеточие» | двоеточие обязательно |
| Нет отступа в ветви | IndentationError | команды ветви — с отступом 4 пробела |
| Последняя команда с отступом | строка выводится только в одной ветви | команда без отступа выполняется всегда |
| `n // 3 == 0` вместо `n % 3 == 0` (задача 1) | неверно на 9; подсказка про частное | делимость определяет остаток |
| Не изменено условие (задача 2) | «Меньшее: 12»; подсказка про знак | при `a > b` в `m` попадает большее |
| Нет ветвления (задача 3) | «12 евро 0 центов»; подсказка про `cent == 0` | вместо одной команды вывода — `if/else` |
| 4★: «Каждому» только в одной ветви | неверно на 20 и 5 | первая строка выводится всегда, до ветвления |
| 5★: разность часов и минут отдельно | «2 ч -25 мин» | перевести оба времени в минуты |
| 7★★: `k - t % k` без ветвления | 15 вместо 0 для 8:45 | при `t % k == 0` ждать не нужно |

Сравнение вывода не различает «е» и «ё» («Остается» засчитывается) и тире разных видов.

## 7. Особые случаи

- **Слабая группа.** Конспект рассчитан на нормальный уровень. Если урок 3 не усвоен, повторение `//` и `%` можно расширить до 10 минут за счёт задач ★★.
- **Сильные ученики:** ★, затем ★★. В 7★★ есть решение без ветвления `(k - t % k) % k` — засчитывается.
- **Отрицательные числа.** Встречаются только в задаче 2 (-3 и -8). Остаток от деления отрицательного числа в задачах не используется.
- **Отступления от спецификации и изменения движка.** (1) Блок-схемы с ветвлением: в движок добавлен узел `branch` (ромб, ветвь «да» слева, «нет» справа, линии сходятся); раньше блок-схемы были только линейными. Уроки 1–3 при пересборке выглядят как раньше. (2) Сравнение вывода не учитывает разницу «е» и «ё» (правило AUTHORING: «ё в выводе не требовать»). (3) Практикум, как в уроках 2–3, — 3 + 2★ + 2★★. (4) В повторении, кроме трёх вопросов, есть одно задание с проверкой; в число решённых задач практикума оно не входит.
