Теория

Шаг 1. Условие и операции сравнения

До сих пор команды программы выполнялись одна за другой, сверху вниз: это следование. Часто действие зависит от данных: чётное число или нечётное, какое из двух чисел больше, хватает ли денег на покупку. Для таких задач служит условие (англ. condition) — высказывание, которое при данных значениях величин либо истинно, либо ложно.

Простое условие записывается с помощью операций сравнения (англ. comparison operators). Результат сравнения в Python — логическое значение: True (истина) или False (ложь). Например, 7 > 3 равно True, а 7 == 3 равно False.

Сравнение на равенство записывается двумя знаками: ==. Один знак = — это присваивание. Условие «число n чётное» записывается так: n % 2 == 0 — остаток от деления на 2 равен нулю.

Шаг 2. Полная форма ветвления

Ветвление (англ. branching) — алгоритмическая конструкция, в которой в зависимости от условия выполняется одна из двух серий команд. В блок-схеме условие записывается в ромбе. Из ромба выходят две линии: «да» — условие истинно, «нет» — условие ложно. В полной форме ветвления на каждой линии своя серия команд; после них линии сходятся, и алгоритм продолжается.

На школьном алгоритмическом языке полная форма записывается так: если <условие> то <серия 1> иначе <серия 2> все. В Python ей соответствуют ключевые слова if («если») и else («иначе»).

Правила записи: после условия и после else ставится двоеточие; команды каждой ветви записываются с отступом в четыре пробела; else стоит точно под if. Команда без отступа после ветвления выполняется в любом случае.

Блок-схема

Программа

n = int(input())
if n % 2 == 0:          # условие
    print("Чётное")     # ветвь «да»
else:
    print("Нечётное")   # ветвь «нет»

Для n = 8: условие 8 % 2 == 0 истинно, вывод Чётное. Для n = 7: 7 % 2 равно 1, условие ложно, выполняется ветвь else, вывод Нечётное.

Шаг 3. Большее из двух чисел

Вводятся два числа a и b. Если a > b, большее число — a, иначе большее — b. Если числа равны, условие ложно и выбирается b: это то же самое значение. Результат записывается в переменную m и выводится после ветвления — одной командой для обеих ветвей.

В каждой ветви может быть несколько команд: все они записываются с одинаковым отступом. Пропущенное двоеточие — синтаксическая ошибка SyntaxError, пропущенный или лишний отступ — ошибка IndentationError.

Блок-схема

Программа

a = int(input())
b = int(input())
if a > b:
    m = a
else:
    m = b
print("Большее:", m)
