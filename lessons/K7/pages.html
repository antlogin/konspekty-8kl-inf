Теория

Шаг 1. Целочисленное деление и остаток

Деление с остатком знакомо по начальной школе: 17 : 5 = 3 (остаток 2). В Python для него есть две операции. Целочисленное деление (англ. floor division) // даёт целую часть частного: 17 // 5 равно 3. Остаток от деления (англ. remainder) % даёт остаток: 17 % 5 равно 2.

Результаты связаны равенством: делимое = делитель · частное + остаток, то есть 17 = 5 · 3 + 2. Остаток всегда меньше делителя. Если остаток равен 0, число делится нацело.

Операции // и % выполняются в том же порядке, что умножение и деление: раньше сложения и вычитания. В блок-схеме и школьном алгоритмическом языке они записываются словами div и mod: m := t div 60, s := t mod 60.

ВыражениеРезультатПояснение
17 // 535 помещается в 17 три раза
17 % 5217 − 5 · 3 = 2

4 % 54делимое целиком составляет остаток

Пример: чётность 
print(8 % 2, 7 % 2)

Вывод: 0 1. Остаток от деления на 2 у чётного числа равен 0, у нечётного — 1.

Пример: перевод единиц 
print(250 // 100, 250 % 100)

Вывод: 2 50. 250 сантиметров — это 2 метра и 50 сантиметров.

Блок-схема

Программа

t = int(input())   # время в секундах
m = t // 60        # полных минут
s = t % 60         # оставшиеся секунды
print(m, s)

Для t = 130: m = 2, s = 10, вывод 2 10. Проверка: 60 · 2 + 10 = 130.

Шаг 2. Цифры числа

Целочисленное деление на 10 отбрасывает последнюю цифру числа: 473 // 10 равно 47. Остаток от деления на 10 и есть последняя цифра: 473 % 10 равно 3. Так же работает деление на 100: 473 // 100 равно 4, 473 % 100 равно 73.

Для трёхзначного числа n: сотни — n // 100, десятки — n // 10 % 10 (сначала отбрасывается последняя цифра, затем берётся последняя цифра результата), единицы — n % 10. Сумма цифр — сумма этих трёх значений.

Программа

n = int(input())
a = n // 100        # сотни
b = n // 10 % 10    # десятки
c = n % 10          # единицы
print(a + b + c)

Трассировочная таблица для n = 473

Шаг 3. Типы данных и их преобразование

Тип данных (англ. data type) определяет, какие значения хранит величина и какие операции с ней выполняются. В этом курсе используются три типа: int — целые числа, float — вещественные числа (с дробной частью), str — строки (текст). Тип значения выводит функция type().

Тип результата зависит от операции. + - * // % с двумя целыми числами дают целое число. Деление / всегда даёт вещественное число. Если в операции участвует вещественное число, результат тоже вещественный: 7.5 // 2 равно 3.0.

Функции int(), float(), str() преобразуют значение в другой тип. Функция int() отбрасывает дробную часть, а не округляет. Округление выполняет функция round(). Вещественное число вводится так: d = float(input()); при вводе дробная часть отделяется точкой.

ТипЗначенияПримерыПреобразование
int — целое числоцелые числа5, -3, 0int("25") → 25; int(7.9) → 7
float — вещественное числочисла с дробной частью2.5, 3.0float("2.5") → 2.5; float(3) → 3.0
str — строкатекст в кавычках"Будва", "25"str(25) → "25"
Пример: округление 
print(int(7.9), round(7.9))
print(round(3.14159, 2))

Вывод: 7 8, затем 3.14. Второй аргумент round() — число знаков после точки.

Пример: число и строка 
print(int("25") + 5)
print("25" + "5")
print(str(25) + " евро")

Вывод: 30, 255, 25 евро. Строки при сложении склеиваются.

Пример: ошибка преобразования 
x = int("2.5")

Ошибка выполнения ValueError: строка «2.5» не записывает целое число. Для дробных значений — float().

# Цена в центах: перевод в евро и центы

print(euro, "евро", cent, "центов")
