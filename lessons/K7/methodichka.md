## 3. Ход урока

**Повторение.** Вопрос 2 (`input()` + `input()` → «45») — мостик к шагу 3 о типах.

**Шаг 1. `//` и `%`.** Записать на доске 17 : 5 = 3 (ост. 2) и проверку 5 · 3 + 2 = 17. Спросить класс, чему равны `4 // 5` и `4 % 5` (частая ошибка — думать, что остаток 0 или «нельзя»). Чётность через `n % 2` показать как применение; сравнение `== 0` не вводить, это урок ветвления. В блок-схемах — div и mod, как в учебнике.

**Шаг 2. Цифры числа.** Трассировка 473 на доске. Ключевое место — десятки `n // 10 % 10`: сначала «отрезать» единицы, потом взять последнюю цифру. Альтернативная запись `n % 100 // 10` тоже верна, её засчитывает проверка.

**Шаг 3. Типы.** Три типа и таблица преобразований. Показать в песочнице `int("2.5")` → ValueError: эта ошибка встретится в задаче 3. `round(2.5)` в Python даёт 2 (округление к чётному) — на уроке не поднимать; в задачах таких случаев нет.

**Разбор кода.** Задание 1 — 1250 → «12 евро 50 центов». Задание 2 — цена упаковки из трёх: `price = int(input()) * 3` (типичная ошибка — умножить только `euro`). Задание 3 — `euro = price / 100` даёт 12.5; исправление `//`. `int(price / 100)` тоже засчитывается, `round(price / 100)` — нет (для 99 центов даёт 1 евро).

**Практикум.** Все задачи проверяются на нескольких наборах, часть скрыта. Темп: задача 1 — 3 мин, 2 — 4, 3 — 4, ★ — по готовности, ★★ — для сильных.

## 4. Эталонные решения

```python
# 1. Заплыв
t = int(input())
m = t // 60
s = t % 60
print(m, "мин", s, "с")
```

```python
# 2. Сумма цифр (заготовка: первые две строки)
n = int(input())
a = n // 100    # сотни
b = n // 10 % 10
c = n % 10
print("Сумма цифр:", a + b + c)
```

```python
# 3. Бензин на поездку (вывод 20.0 при целом результате — верно)
km = int(input())
rate = float(input())
fuel = round(km * rate / 100, 1)
print("Бензин:", fuel, "л")
```

```python
# 4★. Время прибытия (1440 минут в сутках)
h = int(input())
m = int(input())
d = int(input())
t = (h * 60 + m + d) % 1440
print("Прибытие:", t // 60, "ч", t % 60, "мин")
```

```python
# 5★. Число наоборот (120 → 21: число собирается арифметикой, а не склейкой строк)
n = int(input())
a = n // 100
b = n // 10 % 10
c = n % 10
print(c * 100 + b * 10 + a)
```

```python
# 6★★. Микроавтобусы: округление частного вверх без ветвления; засчитываются и (n - 1) // 8 + 1, -(-n // 8)
n = int(input())
print((n + 7) // 8)
```

```python
# 7★★. Подъезд и этаж: нумерация с нуля (n - 1) убирает особый случай последней квартиры подъезда
k = int(input())    # этажей в доме
n = int(input())    # номер квартиры
print("Подъезд:", (n - 1) // (4 * k) + 1)
print("Этаж:", (n - 1) % (4 * k) // 4 + 1)
```

**Повторение:** 1 — `9 6`; 2 — `45`; 3 — `9.0`.

**Разбор кода:** задание 1 — «12 евро 50 центов»; задание 2 — `price = int(input()) * 3`; задание 3 — `euro = price // 100`.

**Проверить себя:** 1 — `4 3`; 2 — `8`; 3 — `10 73`.

## 5. Типичные ошибки

| Ошибка | Что видит ученик | Что ответить |
|---|---|---|
| `/` вместо `//` (задачи 1, 2, задание 3) | «2.1666… мин», «12.5 евро»; подсказка про `/` | `/` всегда даёт вещественное число; целую часть даёт `//` |
| div, mod в Python (задача 1) | SyntaxError; подсказка про блок-схему | в Python — `//` и `%` |
| Перепутаны `//` и `%` | минуты и секунды поменялись местами | `//` — сколько целых раз, `%` — что осталось |
| Десятки как `n // 10` или `n % 100` | «Сумма цифр: 54» / «80» | `n // 10` — 47, а не 7; нужен ещё `% 10` |
| `int(input())` для 6.5 (задача 3) | ValueError в строке 2; подсказка про `float` | дробное число вводится через `float(input())` |
| `round(x)` без второго аргумента (задача 3) | «Бензин: 20 л» вместо 19.5 | второй аргумент — число знаков после точки |
| 4★: не учтён переход через полночь | «24 ч 25 мин» на скрытом тесте | в сутках 1440 минут: `% 1440` |
| 5★: вывод `c, b, a` или склейка строк | «3 7 4» или «021» | требуется одно число: `c * 100 + b * 10 + a` |
| 6★★: `n // 8 + 1` | неверно для 16 и 8 | при делении нацело лишний автобус не нужен; прибавить 7 до деления |
| 7★★: без `n - 1` | квартира 36 «уходит» во второй подъезд | нумерация с нуля |

## 7. Особые случаи

- **Слабая группа.** Этот конспект рассчитан на нормальный уровень. Для группы, которая не справилась с уроком 2, нужен отдельный упрощённый вариант (повторение переменных и ввода + облегчённые задачи на `//` и `%`); он делается отдельно.
- **Сильные ученики:** ★, затем ★★. В 6★★ идея «округления вверх» `(n + k - 1) // k` пригодится на олимпиадах; в 7★★ — переход к нумерации с нуля.
- **Отрицательные числа.** В задачах только неотрицательные числа. Если спросят: `-7 // 2` равно −4, `-7 % 2` равно 1 (Python округляет частное вниз, остаток не отрицательный при положительном делителе).
- **Отступления от спецификации.** Запрет ветвления и `import` в 6★★ и 7★★ проверяется правилами `rules` («Неверно: Ветвление в этой задаче не используется»). Практикум, как и в уроке 2, — 3 + 2★ + 2★★ (по плану курса).
