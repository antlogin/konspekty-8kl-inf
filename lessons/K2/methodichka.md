## 3. Ход урока

**Шаг 1. Способы записи, блок-схемы.** Таблица блоков; обратить внимание: прямоугольник теперь используется — для присваивания. Песочница: добавить комментарий и `print()`.

**Шаг 2. Величины.** Главное различие: `city` (значение) и `"city"` (текст). Вывод нескольких значений через запятую, пробел ставится сам. Типы `int`, `float`, `str` — назвать и показать `type()`; подробно типы — в уроке про ввод и вывод.

**Шаг 3. Присваивание.** На доске трассировочная таблица для `a = 5; b = a + 2; a = 8; b = b + a`. Ключевые вопросы классу: почему `b` не стала 10 после `a = 8`; почему `n = n + 3` не уравнение. Таблица видов ошибок — прочитать вслух, дальше она нужна в задаче 2. Песочница: поменять строки 1 и 2 местами → NameError (переменная используется до присваивания).

**Разбор кода.** Задание 1 — вывод программы с изменением `price` посередине. Задание 2 — изменить одно число (`price = 7` → `8`), цена в сезон пересчитывается сама; запрещены числа в `print()`. Задание 3 — опечатка `prise` (NameError).

## 5. Типичные ошибки

| Ошибка | Что видит ученик | Что ответить |
|---|---|---|
| Имя переменной в кавычках: `print("Цена:", "price")` | вывод «price» вместо числа; подсказка про кавычки | в кавычках — текст, без кавычек — значение |
| `:=` в Python (задача 1) | SyntaxError; подсказка «знак := используется в блок-схеме» | в Python присваивание — `=` |
| Время без кавычек: `time = 14:30` | SyntaxError | двоеточие внутри числа недопустимо, это текст — в кавычках |
| Готовое число вместо переменной в `print()` или `total = 6` | «Неверно: числа в командах print() не записываются…» | при изменении цены программа должна пересчитать всё сама |
| `n - 5` без присваивания (задача 4) | вывод не меняется | результат вычисления нужно записать в переменную: `n = n - 5` |
| `a = b`, затем `b = a` (задача 5) | обе переменные «Будва»; подсказка про третью переменную | присваивание стирает старое значение |
| Цены в кавычках `water = "2"` (задача 3) | «Итого: 24 евро» | `"2" + "4"` склеивает строки; числа пишутся без кавычек |
| Опечатка в имени (`prise`, `Price`) | NameError с номером строки | имя пишется точно, большие и малые буквы различаются |
