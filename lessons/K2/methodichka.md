## 3. Ход урока

**Шаг 1. Величины и присваивание.** Таблица блоков (параллелограмм теперь и для ввода). Трассировочная таблица для `a = 5; b = a + 2; a = 8; b = b + a` на доске; вопрос классу: почему `b` не стала 10 после `a = 8`. Песочница: поменять строки 1 и 2 → NameError.

**Шаг 2. Ввод.** Показать, что поле ввода появляется в окне вывода. Ключевая демонстрация: убрать `int()` → TypeError «текст и число нельзя объединять». Таблица трёх видов ошибок — нужна в задаче 2.

**Шаг 3. Арифметика.** `2 + 3 * 4` и `(2 + 3) * 4`; `6 / 2` даёт `3.0` (тип `float`). `//` и `%` не вводить — отдельное занятие.

**Разбор кода.** Задание 1 — вывод при вводе 4 и 3. Задание 2 — добавить сбор 2 евро к сумме (`total = price * count + 2`; типичная ошибка — `(price + 2) * count`). Задание 3 — логическая ошибка: `count = input()` даёт «3333» (число × строка повторяет строку).

**Практикум.** Все задачи проверяются на нескольких наборах входных данных, часть скрыта: подогнать вывод под пример не получится. Темп: задача 1 — 3 мин, 2 — 4, 3 — 3–4, ★ — по готовности, ★★ — для сильных.

## 4. Эталонные решения

```python
# 1. Билеты в аквапарк
adults = int(input())
kids = int(input())
total = adults * 10 + kids * 5
print("Стоимость:", total, "евро")
```

```python
# 2. Три ошибки: строка 5 — запятая (синтаксическая); строка 2 — int (выполнения, TypeError);
# строка 3 — скобки (логическая: посадка умножалась на 2)
km = int(input())
total = km * 2 + 3
print("Расстояние:", km, "км")
print("К оплате:", total, "евро")
```

```python
# 3. Время в пути
h = int(input())
m = int(input())
total = h * 60 + m
print("Всего минут:", total)
```

```python
# 4★. Счёт в кафе (вывод 20.0: результат / — float)
bill = int(input())
n = int(input())
each = (bill + 10) / n
print("Каждый платит:", each, "евро")
```

```python
# 5★. Пассажиры автобуса
n = int(input())
out = int(input())
new = int(input())
print("Бар:", n)
n = n - out
print("Петровац:", n)
n = n + new
print("Будва:", n)
```

```python
# 6★★. x в седьмой степени за 4 умножения (7 = 4 + 2 + 1); засчитывается и x3 = x2 * x, x6 = x3 * x3, x6 * x
x = int(input())
x2 = x * x
x4 = x2 * x2
x7 = x4 * x2 * x
print(x7)
```

```python
# 7★★. Обмен без третьей переменной
a = int(input())
b = int(input())
a = a + b   # для 17 и 5: a = 22
b = a - b   # b = 17
a = a - b   # a = 5
print("a =", a)
print("b =", b)
```

**Разбор кода:** задание 1 — «Билетов: 3 / К оплате: 12 евро»; задание 2 — `total = price * count + 2`; задание 3 — `count = int(input())`.

**Проверить себя:** 1 — прямоугольник, `x = 10`; 2 — `8 5`; 3 — `3.5 14`.

## 5. Типичные ошибки

| Ошибка | Что видит ученик | Что ответить |
|---|---|---|
| `input()` без `int()` | TypeError «текст и число нельзя объединять» или странный результат («53», «3333») | `input()` всегда возвращает строку |
| Имя переменной в кавычках | вывод «total» вместо числа | в кавычках — текст, без кавычек — значение |
| `:=` в Python (задача 1) | SyntaxError; подсказка про блок-схему | в Python присваивание — `=` |
| Нет запятой в `print("…" total)` | SyntaxError | значения в `print()` разделяются запятыми |
| Скобки не там (`(km + 3) * 2`, `bill + 10 / n`) | «Неверно: тест N…» | порядок действий: `*` и `/` раньше `+` и `-` |
| Подгонка под пример (`print("Стоимость: 35 евро")`) | «Неверно: скрытый тест…» | программа должна работать для любых введённых чисел |
| 4★: ожидают 20, а выводится 20.0 | — | результат `/` всегда вещественный; это верно |
| 5★: `n - out` без присваивания | вывод не меняется | результат нужно записать: `n = n - out` |
| 6★★: семь множителей подряд | «Знаков умножения больше четырёх» | использовать уже вычисленные степени |
| 7★★: `a = b`, затем `b = a` | обе переменные равны | присваивание стирает значение; сумма хранит оба числа |

- **Слабая группа.** Обязательный минимум — задачи 1 и 3; задачу 2 разобрать фронтально по таблице видов ошибок.

- **Отступления от спецификации.** Требования к тексту программы (только сложение и вычитание в 7★★, не более четырёх `*` в 6★★, присваивания вида `n = n - out` в 5★) проверяются правилами `rules`, результат показывается как «Неверно: …» с названием требования.
