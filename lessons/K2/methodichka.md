## 3. Ход урока

**Повторение.** Остановка после вопроса 1: класс вслух называет вывод (пустая строка между словами).

**Шаг 1. Способы записи.** Показать три записи одного алгоритма (список, блок-схема, программа). Вопрос классу: кому предназначена каждая запись (человеку или компьютеру). Песочница: добавить блок вывода и соответствующую команду.

**Шаг 2. Блок-схемы.** Таблица обозначений (ГОСТ 19.701). Прочитать блок-схему «Билет» сверху вниз; обратить внимание на блок «Вывод: пустая строка» ↔ `print()`. Песочница: убрать блок и команду, сравнить вывод.

**Шаг 3. Среда и комментарии.** Сопоставить элементы среды с областями песочницы. Комментарий: `#` до конца строки; отключение команды комментарием. Песочница: добавить комментарий, закомментировать команду.

**Разбор кода.** Задание 1 — «Проверить» после выбора варианта (комментарии не выводятся, пустая строка есть). Задание 2 — изменить `10:00` на `10:30`, комментарии сохранить (проверяется правилом «не менее двух комментариев»). Задание 3 — скобка не закрыта в строке 2: сообщение указывает строку с открытой скобкой.

**Практикум.** Темп: задача 1 — 2–3 мин, задача 2 — 3–4, задача 3 — 4–5, ★ — по готовности. В задаче 3 ошибки выдаются по очереди (сначала синтаксическая, затем NameError): важно запускать после каждого исправления.

## 4. Эталонные решения

**Разбор кода.**

```python
# Расписание парома
print("Паром: Каменари - Лепетане")
print("Отправление: 10:30")   # время отправления
print()
print("Хорошего дня!")
```

```python
# Остановки маршрута
print("Бар")
print("Будва")
print("Котор")
```

Задание 1: вариант без строки с комментарием и без «# время отправления» — «Паром… / Отправление: 10:00 / пустая строка / Хорошего дня!».

**Практикум.**

| Задача | Решение |
|---|---|
| 1. Блок-схема в программу | `print("Рейс: Бар - Улцинь")`, `print("Отправление: 08:30")`, `print("Прибытие: 09:10")` |
| 2. Визитка рейса | первой строкой `# Визитка рейса`; затем три `print` с данными, `print()`, `print("Приятного пути!")` |
| 3. Две ошибки | строка 2: `print("Список остановок")` (закрыть кавычку), строка 4: `print("Будва")` (опечатка `pront`) |
| 4★. Отключение команд | `# print("Будва")` и `# print("Херцег-Нови")`; остальные строки без изменений |
| 5★. Расписание в рамке | комментарий в программе и пять `print`: `"+---------------+"`, `"\| Бар     08:30 \|"`, `"\| Будва   09:15 \|"`, `"\| Котор   10:00 \|"`, `"+---------------+"` |

Эталон задачи 5★:

```python
# Расписание в рамке
print("+---------------+")
print("| Бар     08:30 |")
print("| Будва   09:15 |")
print("| Котор   10:00 |")
print("+---------------+")
```

**Проверить себя:** 1 — графической записью (блок-схемой); 2 — параллелограммом; 3 — «Привет», «Конец» (строка с `# print("Пока")` отключена).

## 5. Типичные ошибки

| Ошибка | Что видит ученик | Что ответить |
|---|---|---|
| В задаче 1 в кавычки попало слово «Вывод:» | подсказка «Слово „Вывод:“ — подпись блока» | подпись блока — обозначение действия, а не текст |
| В задаче 2 комментарий не первой строкой или внутри `print` | «Первой строкой программы требуется комментарий…» | комментарий — строка, начинающаяся с `#`, а не текст в кавычках |
| Пропущена пустая строка | «ожидалось строк: 5, получено: 4» | нужна команда `print()` |
| Задача 3: исправлена одна ошибка | следующая ошибка появляется после запуска | интерпретатор останавливается на первой ошибке |
| Задача 4: строки удалены, а не закомментированы | «Отключаемые команды должны остаться в программе в виде комментариев…» | комментарий отключает команду, не удаляя её |
| Задача 5: число пробелов | «строка вывода N: ожидалось …, получено …» | пробелы входят в вывод |
| Знак `#` вместо `//` или `--` | NameError / SyntaxError | в Python комментарий начинается со знака `#` |

Содержательные ошибки: путают блоки «Вывод» (параллелограмм) и «Действие» (прямоугольник); считают, что комментарий — это блок в блок-схеме; путают «программу» и «блок-схему» как способы записи.
