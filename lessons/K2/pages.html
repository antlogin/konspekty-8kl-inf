Цель занятия

Усвоить способы записи алгоритмов, научиться читать блок-схемы линейных алгоритмов и записывать их на языке Python, различать элементы среды программирования и использовать комментарии.

Планируемый результат. Называются способы записи алгоритма; по блок-схеме линейного алгоритма составляется программа на Python; в программе записываются комментарии; по сообщению об ошибке определяется строка с ошибкой и ошибка исправляется.

Теория

Шаг 1. Способы записи алгоритмов

Один и тот же алгоритм записывается по-разному. Выбор способа зависит от того, кто будет выполнять алгоритм и кому его требуется прочитать.

Словесная запись (на естественном языке) описывает шаги обычными предложениями: так записаны рецепты и инструкции. Она понятна человеку, но допускает неоднозначные толкования.

Графическая запись представляет алгоритм схемой из фигур, соединённых стрелками (блок-схема; англ. flowchart). Запись на языке программирования (программа) предназначена для компьютера и не допускает неоднозначности: каждая команда понимается строго определённым образом.

Словесная запись

  1. Вывести название порта: Бар.
  2. Вывести номер причала: 3.
  3. Вывести время рейса: 14:30.

Программа на Python

print("Порт: Бар")
print("Причал: 3")
print("Рейс: 14:30")

Блок-схема

Три записи описывают один и тот же алгоритм. Алгоритм, в котором шаги выполняются один за другим без ветвлений и повторений, называется линейным.

Шаг 2. Блок-схемы

Блок-схема строится из блоков — геометрических фигур, внутри которых записано действие. Начертание и назначение блоков устанавливает государственный стандарт (ГОСТ 19.701; в международной практике используется схожий стандарт ISO 5807).

Блоки соединяются линиями со стрелками, которые показывают порядок выполнения. Основное направление — сверху вниз. Алгоритм имеет один блок «Начало» и один блок «Конец».

В линейной блок-схеме блоки следуют друг за другом, каждый блок имеет один вход и один выход. Блок «Условие» (ромб) имеет два выхода; он используется в ветвлениях и в этом конспекте только называется.

БлокНазваниеНазначениеПример в программе
Терминатор (овал)начало и конец алгоритмапервая и последняя строки программы
Ввод и вывод (параллелограмм)вывод данных на экран, ввод с клавиатурыprint("Бар")
Процесс (прямоугольник)обработка данных, вычислениевычисления (в следующих конспектах)
Решение (ромб)проверка условия, выбор путиветвление (в следующих конспектах)

Блок-схема

Программа на Python

print("Билет")
print()
print("Подгорица - Котор")

Каждому блоку вывода соответствует одна команда print(). Блок «Вывод: пустая строка» записывается командой print() без текста.

Шаг 3. Среда Python и комментарии

Программы записываются и выполняются в среде программирования (англ. programming environment). Среда объединяет редактор текста программы, средство запуска, окно вывода результата и окно сообщений об ошибках. Именно такая среда используется в песочнице этого конспекта.

Программу на Python выполняет интерпретатор (англ. interpreter): он читает команды сверху вниз и выполняет каждую по очереди. Если в строке найдена ошибка, интерпретатор останавливается и сообщает вид ошибки и номер строки.

Комментарий (англ. comment) — пояснение для человека, которое интерпретатор пропускает. Комментарий начинается со знака # и продолжается до конца строки. Комментарием можно временно отключить команду, не удаляя её.

Элемент средыНазначениеВ песочнице
Редакторзапись и правка текста программыполе с номерами строк слева

Окно выводарезультат работы программыобласть «Вывод программы»

Программа с комментариями

# Расписание парома
print("Паром: Каменари - Лепетане")
print("Отправление: 10:00")   # время
# print("Не выводится")

В вывод попадут две строки: строки с # интерпретатор пропускает; последняя команда отключена.

Блок-схема той же программы

В блок-схеме комментарий отдельного блока не образует.
