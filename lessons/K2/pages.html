Теория

Шаг 1. Переменные и команда присваивания

Способы записи алгоритма: словесный (обычными предложениями), графический — блок-схема (англ. flowchart) и программа на языке программирования. Алгоритм, шаги которого выполняются один за другим, без ветвлений и повторений, называется линейным.

Алгоритм работает с величинами. Константа — величина, значение которой не меняется. Переменная (англ. variable) — величина, у которой есть имя, тип и значение; значение можно менять при выполнении программы.

Имя переменной записывается латинскими буквами (так принято), может содержать цифры и знак _, но не начинается с цифры. Имя не должно совпадать с командами Python: после input = 5 команда input() перестаёт работать.

Команда присваивания записывает значение в переменную: в блок-схеме a := 5, в Python a = 5. Сначала вычисляется правая часть, затем результат записывается в переменную; прежнее значение теряется. Поэтому n = n + 3 — не уравнение, а команда «увеличить n на 3».

Пример: переменная и константа 
price = 7

Переменная — price, константа — 7.

Пример: имя и значение 
city = "Будва"
print(city)
print("city")

Вывод: Будва, затем city. Имя без кавычек — значение переменной; в кавычках — обычный текст.

Пример: несколько значений в print() 
print("Цена:", 7, "евро")

Вывод: Цена: 7 евро. Значения перечисляются через запятую, при выводе между ними ставится пробел.

Пример: n = n + 3 
n = 5
n = n + 3

После второй строки в n записано 8; число 5 потеряно.

Шаг 2. Ввод данных

Если исходные данные вводятся при выполнении, а не записаны в программе, одна программа решает задачу для любых данных (свойство массовости из первого урока).

Функция input() приостанавливает программу и ждёт, пока с клавиатуры будет введено значение и нажата клавиша Enter. Текст в скобках, например input("Имя: "), выводится как подсказка. В задачах практикума подсказку писать не обязательно: проверка её не учитывает.

Значение, полученное от input(), всегда имеет тип str (строка), даже если введены цифры. Для вычислений строка преобразуется в целое число функцией int(): n = int(input()).

Блок-схема

Программа

name = input("Имя: ")
age = int(input("Возраст: "))
print("Привет,", name)

Имя — текст, поэтому int() не нужен. Возраст участвует в вычислении, поэтому преобразуется в число.

Шаг 3. Арифметические операции

Выражение записывается в одну строку: дробь — через знак /, со скобками. Знак умножения не пропускается: 2 * x, а не 2x; знаки «×» и «·» Python не понимает.

Порядок действий — как в математике: сначала умножение и деление, затем сложение и вычитание; действия одного уровня выполняются слева направо. Скобки изменяют порядок действий.

Результат деления / всегда вещественное (дробное) число, тип float, даже когда делится нацело: 6 / 2 равно 3.0. Дробная часть отделяется точкой, и при вводе тоже. Целочисленное деление и остаток рассматриваются в отдельном занятии.

ОперацияЗнакПримерРезультат
сложение+7 + 29
вычитание-7 - 25
умножение*7 * 214
деление/7 / 23.5
скобки( )(2 + 3) * 420 (без скобок — 14)
Пример: дробь в одну строку

Среднее двух чисел: сумма a + b, делённая на 2.

m = (a + b) / 2

Без скобок a + b / 2 на 2 делится только b.

Пример: слева направо 
print(8 - 3 - 2)

Вывод: 3, а не 7: сначала 8 − 3, затем − 2.

Пример: точка, а не запятая 
print(2.5)
print(2,5)

Вывод: 2.5, затем 2 5 — во второй строке два числа, а не 2,5.

# Покупка билетов на паром
price = int(input())    # цена одного билета, евро
count = int(input())    # количество билетов
total = price * count
print("Билетов:", count)
print("К оплате:", total, "евро")

Итог

Вывод

  • Величина — константа или переменная. У переменной есть имя, тип и значение.
  • Имя и значение: print(city) выводит значение переменной (Будва), print("city") — текст city.
  • Присваивание (:= в блок-схеме, = в Python): сначала вычисляется правая часть, затем результат записывается в переменную, прежнее значение теряется. Значения отслеживаются трассировочной таблицей.
  • Ввод: input() возвращает строку (str); для вычислений — int(input()).
  • Арифметика: + - * /; умножение и деление раньше сложения и вычитания, скобки меняют порядок. Результат / — вещественное число (float), дробная часть отделяется точкой.
  • Ошибки: синтаксическая — программа не запускается; выполнения — останавливается на строке; логическая — работает, но результат неверный.
