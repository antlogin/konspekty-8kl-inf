Планируемый результат. По блок-схеме составляется программа с вводом, вычислением и выводом; выполняется трассировка последовательности присваиваний; учитывается порядок действий; по сообщению Python определяется вид ошибки и строка с ней.

Теория

Шаг 1. Величины и команда присваивания

Алгоритм записывается словесно, в виде блок-схемы (англ. flowchart) или на языке программирования. Блок-схема строится из блоков по ГОСТ 19.701 и читается сверху вниз по стрелкам. Алгоритм, шаги которого выполняются один за другим, называется линейным.

Алгоритм работает с величинами. Константа не меняет значения: 7, "Будва". Переменная (англ. variable) имеет имя, тип и значение, которое может меняться. Имя состоит из латинских букв, цифр и знака _ и не начинается с цифры. Имя без кавычек обозначает значение, текст в кавычках выводится как есть.

Команда присваивания записывает значение в переменную: в блок-схеме a := 5, в Python a = 5. Сначала вычисляется правая часть, затем результат записывается в переменную; прежнее значение теряется. Поэтому n = n + 3 — не уравнение, а команда «увеличить n на 3». Значения переменных отслеживаются трассировочной таблицей.

Шаг 2. Ввод данных

Программа становится массовой, если исходные данные не записаны в ней, а вводятся при выполнении. Функция input() останавливает программу, ждёт ввода с клавиатуры и возвращает введённое значение. Текст в скобках, например input("Имя: "), выводится как подсказка.

Значение, полученное от input(), всегда имеет тип str (строка), даже если введены цифры. Для вычислений строка преобразуется в целое число функцией int(): n = int(input()). Без преобразования "5" + "3" даёт строку «53», а "5" + 3 — ошибку TypeError.

Ошибки в программах бывают трёх видов. Синтаксическая ошибка обнаруживается до запуска; ошибка выполнения останавливает программу на строке с ошибкой; при логической ошибке программа работает, но выводит неверный результат.

Шаг 3. Арифметические операции

Выражение в правой части присваивания записывается в строку с помощью знаков операций. Порядок действий — как в математике: сначала умножение и деление, затем сложение и вычитание, слева направо. Скобки изменяют порядок действий.

Результат деления / всегда имеет тип float (вещественное число): 7 / 2 равно 3.5, 6 / 2 равно 3.0. Дробная часть отделяется точкой. Целочисленное деление и остаток рассматриваются в отдельном занятии.

# Покупка билетов на паром
price = int(input())    # цена одного билета, евро
count = int(input())    # количество билетов
total = price * count
print("Билетов:", count)
print("К оплате:", total, "евро")
