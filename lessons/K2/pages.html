Планируемый результат. По блок-схеме составляется программа на Python с переменными; различаются имя и значение переменной; выполняется трассировка последовательности присваиваний; по сообщению Python определяется вид ошибки и строка с ней.

Теория

Шаг 1. Способы записи алгоритмов. Блок-схемы

Один и тот же алгоритм записывается по-разному. Словесная запись (на естественном языке) понятна человеку без подготовки, но допускает неоднозначные толкования. Графическая запись — блок-схема (англ. flowchart) — наглядно показывает порядок шагов. Запись на языке программирования (программа) предназначена для компьютера и неоднозначности не допускает.

Блок-схема строится из блоков по ГОСТ 19.701 (международный аналог — ISO 5807). Блоки соединяются стрелками; основное направление — сверху вниз. Алгоритм, в котором шаги выполняются один за другим без ветвлений и повторений, называется линейным.

Комментарий (англ. comment) — пояснение для человека в тексте программы. Он начинается со знака # и продолжается до конца строки; интерпретатор его пропускает. В блок-схеме комментарий отдельного блока не образует.

БлокНазваниеНазначениеВ Python
Терминатор (овал)начало и конец алгоритмапервая и последняя строки программы
Ввод и вывод (параллелограмм)вывод данных на экран, ввод с клавиатурыprint("Бар")
Процесс (прямоугольник)присваивание, вычислениеx = 5

Словесная запись

  1. Вывести название порта: Бар.
  2. Вывести номер причала: 3.
  3. Вывести время рейса: 14:30.

Программа на Python

print("Порт: Бар")
print("Причал: 3")
print("Рейс: 14:30")

Шаг 2. Величины: имя, тип, значение

Алгоритм работает с величинами (данными). Величина, значение которой не меняется, называется константой: 7, "Будва". Величина, значение которой может меняться при выполнении алгоритма, называется переменной (англ. variable). У переменной есть имя, тип и значение.

Имя переменной в Python состоит из латинских букв, цифр и знака подчёркивания и не начинается с цифры: price, city_2. Большие и малые буквы различаются: Price и price — разные имена. Тип определяет, какие значения хранятся и какие действия с ними допустимы: int — целое число, float — дробное число (через точку: 2.5), str — строка (текст в кавычках). Тип значения сообщает функция type().

Имя без кавычек обозначает значение переменной, текст в кавычках выводится как есть. В команде print() через запятую перечисляется несколько значений; между ними при выводе ставится пробел.

Программа

city = "Будва"      # str
price = 7           # int
print("Рейс до", city)
print("city")
print("Цена:", price, "евро")

Вывод

Рейс до Будва
city
Цена: 7 евро

Во второй строке вывода — слово city: в кавычках имя переменной становится обычным текстом.

Шаг 3. Команда присваивания. Трассировка

Команда присваивания записывает значение в переменную. В блок-схеме и школьном алгоритмическом языке она обозначается знаком :=, в Python — знаком =: a = 5. Слева — имя переменной, справа — выражение. Сначала вычисляется правая часть, затем результат записывается в переменную; прежнее значение при этом теряется.

Поэтому запись n = n + 3 — не уравнение, а команда: взять текущее значение n, прибавить 3 и записать результат в n. Команда b = a копирует значение: последующее изменение a на b не влияет.

Значения переменных при выполнении программы удобно отслеживать трассировочной таблицей: строка таблицы — команда, столбец — переменная. Если переменная используется раньше, чем ей присвоено значение, Python останавливается с ошибкой NameError.

Блок-схема и программа

a = 5
b = a + 2
a = 8
b = b + a
print(a, b)
