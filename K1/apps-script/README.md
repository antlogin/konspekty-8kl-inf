# Google Apps Script для конспектов Learn-it

Скрипт принимает данные от конспекта К1 (и следующих конспектов курса): проверяет кодовое слово группы, записывает события в таблицы на Google Диске учителя, хранит снимки работ для восстановления. Развёртывание выполняется один раз на аккаунте учителя; для К2–К20 тот же адрес подходит без изменений.

Файл скрипта: [`Code.gs`](Code.gs).

## Что понадобится

- аккаунт Google, на Диске которого должны появляться таблицы (аккаунт учителя);
- кодовые слова трёх групп: **Компас ср**, **Компас пт**, **ФШ пн** (слова придумывает учитель; в HTML конспекта слов нет);
- файл конспекта `K1_Algoritmy_i_ispolniteli.html` для вставки адреса.

## Шаг 1. Создать проект

1. Войти в аккаунт учителя и открыть <https://script.google.com>.
2. Нажать **Новый проект** (New project).
3. Название проекта (слева вверху): «Learn-it: приём данных».

## Шаг 2. Вставить код

1. В редакторе открыть файл `Code.gs`, выделить всё содержимое (Ctrl+A) и удалить.
2. Открыть [`Code.gs`](Code.gs) из этой папки, скопировать весь текст и вставить в редактор.
3. Нажать **Сохранить проект** (значок дискеты или Ctrl+S).

## Шаг 3. Задать свойства скрипта

1. Слева выбрать **Настройки проекта** (значок шестерёнки).
2. Внизу страницы, в разделе **Свойства скрипта** (Script properties), нажать **Добавить свойство скрипта** (Add script property).
3. Создать свойство:

   | Свойство | Значение |
   |---|---|
   | `CODEWORDS` | JSON с соответствием «слово → группа» |

   Пример значения (**слова заменить своими**; значения `REPLACE_ME…` скрипт не принимает):

   ```json
   {"REPLACE_ME слово компас среда": "Компас ср", "REPLACE_ME слово компас пятница": "Компас пт", "REPLACE_ME слово фш понедельник": "ФШ пн"}
   ```

   Названия групп справа (`Компас ср`, `Компас пт`, `ФШ пн`) становятся названиями папок на Диске и значениями в таблицах. Слово может состоять из нескольких слов; регистр, буква «ё» и лишние пробелы при проверке не учитываются.
4. Нажать **Сохранить свойства скрипта**.
5. Необязательные свойства:
   - `ROOT_FOLDER_ID` — идентификатор папки на Диске (часть адреса после `/folders/`), если таблицы должны лежать не в «Learn-it результаты» в корне Диска;
   - `CODEWORDS_<courseId>` — отдельные слова для другого курса (например, `CODEWORDS_physics-9`); для остальных курсов действует `CODEWORDS`.

Слова можно менять в любой момент: новые значения действуют сразу, повторное развёртывание не требуется.

## Шаг 4. Проверить настройку и выдать доступ

1. В редакторе выбрать вверху функцию **`testSetup`** и нажать **Выполнить** (Run).
2. Откроется окно запроса доступа: **Просмотреть разрешения** → выбрать аккаунт → если Google сообщает «Приложение не проверено», нажать **Дополнительно** → **Перейти на страницу «Learn-it: приём данных» (небезопасно)** → **Разрешить**. Скрипт принадлежит самому учителю; запрашиваются доступы к Google Диску и Таблицам.
3. В нижней панели **Журнал выполнения** должны появиться строки: число кодовых слов, названия групп и ссылка на корневую папку на Диске. Строка «ОШИБКА: свойство CODEWORDS не задано…» означает, что шаг 3 не выполнен или в значении остались заглушки.

## Шаг 5. Опубликовать как веб-приложение

1. Нажать **Начать развёртывание** (Deploy) → **Новое развёртывание** (New deployment).
2. Рядом с надписью «Выберите тип» нажать шестерёнку → **Веб-приложение** (Web app).
3. Заполнить:
   - **Описание:** `Learn-it приём данных v1`;
   - **Запуск от имени** (Execute as): **Я** (Me);
   - **У кого есть доступ** (Who has access): **Все** (Anyone). Ученики не входят в аккаунт Google; без этого параметра запросы отклоняются.
4. Нажать **Развернуть** (Deploy) и скопировать **URL веб-приложения** (Web app URL). Он выглядит так: `https://script.google.com/macros/s/AKfycb…/exec` и заканчивается на `/exec`.
5. Открыть этот адрес в браузере: должен отобразиться ответ вида `{"ok":true,"service":"learnit-collector","version":"1.0.0"}`. Адрес, оканчивающийся на `/dev`, не подходит: он работает только для владельца.

## Шаг 6. Вставить адрес в конспект

1. Открыть `K1_Algoritmy_i_ispolniteli.html` в текстовом редакторе.
2. Найти блок `TELEMETRY_CONFIG` (в начале раздела `<script id="telemetry-config">`).
3. В строке с `name: "google"` заменить значение `url`:

   ```js
   { name: "google", url: "https://script.google.com/macros/s/AKfycb…/exec", enabled: true },
   ```

4. В той же настройке заменить заглушку `courseUrl: "https://REPLACE_ME.learn-it.app/"` на адрес сайта курса (в скрипте адрес только сохраняется в данных, на работу он не влияет).
5. Сохранить файл. Адрес Yandex (`name: "yandex"`) остаётся с `enabled: false`; включение — заменой `false` на `true`.

## Шаг 7. Пробный запуск

1. Открыть конспект, ввести кодовое слово группы, имя и фамилию (можно пробные), решить одну задачу в «Практикуме» и нажать «Проверить».
2. Через несколько секунд на Google Диске должна появиться структура:

   ```text
   Learn-it результаты /
     Информатика 8 /
       <группа> /
         К1 Алгоритмы и исполнители. Свойства алгоритмов   (таблица)
         Журнал курса                                       (таблица)
         Файлы работ /                                      (после «Завершить занятие»)
   ```

3. Листы таблицы урока:

   | Лист | Содержимое |
   |---|---|
   | События | все события, строка на событие; ключ `(attemptId, seq)` исключает дубли |
   | Попытки | строка на попытку: ученик, начало, последняя активность, окончание, решено задач, число восстановлений |
   | Сводка | ученик × задача: засчитано, запуски, проверки, подсказки (ступени и автоматические), время до решения |
   | Снимки | последнее состояние работы каждого ученика (для восстановления после сбоя) |
   | Сданные работы | результат кнопки «Завершить занятие»; полный JSON — файл в папке «Файлы работ» |

   «Журнал курса» — одна таблица на группу: строка на ученика, столбец на конспект (`решено/всего · минут`).
4. Пробные строки можно удалить из таблиц вручную; таблицы создаются заново только при удалении самих файлов.

## Как это работает

- Конспект отправляет `POST` с заголовком `Content-Type: text/plain` (preflight не требуется) и JSON в теле. Поле `action`: `checkWord`, `events`, `saveSnapshot`, `getSnapshot`.
- Курс (`courseId`, `courseTitle`) и урок (`lessonId`, `lessonTitle`) приходят в каждом запросе, поэтому один скрипт обслуживает любые курсы и уроки; таблицы создаются по первому событию.
- Слово проверяется на сервере; группа определяется по слову. Слово, не найденное в свойствах, **не блокирует приём событий**: такие данные записываются в группу «Не проверена» (ученик, допущенный при недоступности скрипта, не теряет работу).
- Запись выполняется под `LockService` (короткие операции, ожидание до 20 с); при занятости скрипт отвечает `busy`, а конспект повторяет отправку позже без потери данных. Конспект отправляет пакеты раз в 30 с, поэтому при 12–15 учениках нагрузка около одного обращения в 2 секунды.
- Значения, начинающиеся с `=`, `+`, `-`, `@`, записываются как текст (формулы из имён учеников не выполняются).

## Обновление кода

После изменения `Code.gs`: **Начать развёртывание → Управление развёртываниями → значок карандаша → Версия: Новая версия → Развернуть**. Адрес `/exec` не меняется.

## Если что-то не работает

| Признак | Причина и решение |
|---|---|
| В конспекте указано «группа не проверена», хотя слово верно | адрес в `TELEMETRY_CONFIG` не совпадает с `/exec`, у развёртывания не выбран доступ «Все», либо свойство `CODEWORDS` не задано (запустить `testSetup`) |
| «Кодовое слово не найдено» при верном слове | слово в `CODEWORDS` содержит `REPLACE_ME` или опечатку; JSON в значении некорректен (кавычки только двойные) |
| Таблицы не появляются | не выдан доступ к Диску (повторить шаг 4); в журнале выполнений (Executions) есть ошибка `server_error` |
| Ответ `busy` | одновременно много запросов; конспект повторит отправку сам |
| Данные ушли в группу «Не проверена» | у ученика слово не прошло проверку; строки можно перенести вручную |

## Данные учеников

Скрипт собирает имя, фамилию (или код анонимного входа), код ученика, события работы и последний код каждой задачи. Сбор подробных данных о детях стоит согласовать со школой (одна строка в положении или в информации для родителей).
