# Как забрать готовые конспекты и опубликовать

Схема прежняя: файлы создаются здесь, в репозитории, затем учитель скачивает готовые HTML, кладёт их в локальную папку занятия курса, а проект публикации выполняет стандартный цикл (`npm run update` → проверка → `git push`; `ADD_NEW_COURSE.md`, `PUBLISHING_WORKFLOW.md` из документации Learn-it).

## Что брать

Только собранные HTML (по одному на урок). Номеров уроков в названиях файлов нет: папка и файл называются по теме.

| Урок | Файл |
|---|---|
| Первая программа на Python | `Pervaya_programma/Pervaya_programma.html` (раньше `K1/K1_Algoritmy_i_ispolniteli.html`; изменилось только название) |
| Переменные, ввод и арифметика | `Peremennye_vvod_arifmetika/Peremennye_vvod_arifmetika.html` |
| Черепаха | `K3/K3_Ispolnitel_Cherepakha.html` — перенесена в конец курса, пока не публиковать |

Скачивать целиком: архивом ветки (`https://github.com/antlogin/konspekty-8kl-inf/archive/refs/heads/claude/affectionate-lovelace-yc6y43.zip`, после слияния PR — `…/refs/heads/main.zip`), через `git clone` или кнопкой «Download raw file» на GitHub. Из окна просмотра в приложении Claude файл скачивается обрезанным (около 1,1 МБ).

Не публиковать: `LOCAL_metodichka_*.md` (служебное, `LOCAL_` с подчёркиванием не синхронизируется), `apps-script/`, `engine/`, `lessons/`, `tools/`, `course.json`, `AUTHORING.md`.

## Пересборка фрагмента сайта (25.10.2026)

Опубликовать две папки: `Pervaya_programma/` и `Peremennye_vvod_arifmetika/` (в каждой один HTML). Из папки курса на сайте удалить старую папку `K1/` с `K1_Algoritmy_i_ispolniteli.html` (её заменяет «Первая программа на Python»), а также `K2/` и `K3/`, если они туда попадали. Номера в каталоге заданы явно метатегом `catalog:number` (1 и 2), поэтому переименование файла первого урока номер не сдвигает. Черепаху (`K3/`) не публиковать.

## Что уже настроено

- Адрес скрипта приёма данных подставлен в файлы; кодовые слова заданы в свойствах скрипта и в файлах отсутствуют.
- Метатеги каталога (`catalog:title` без «Занятие N», `catalog:type=lesson`, тема, описание, теги) заполнены. Строку пути, ссылку в каталог и счётчик Метрики вставляет сборка сайта.

## Адрес сайта курса

В файлах записан адрес `https://info-8-class.learn-it.app/` (`courseUrl` в `course.json`; в данных он только сохраняется и на работу не влияет). Если адрес сменится, заменить его в `course.json` и выполнить `node tools/build.js --all`.

Заглушек в файлах не осталось. Вне репозитория остаётся подключение курса (`target`, запись в `sites.json` и `sources.local.json`) — стандартным способом.

## Обновление конспекта

Исправления вносятся здесь (`lessons/K<N>/`, правила — `AUTHORING.md`), собираются `node tools/build.js K<N>` и проверяются `node tools/verify.js K<N>`; готовый HTML скачивается заново и заменяет файл в папке занятия. Собранные HTML вручную не правят (кроме `courseUrl`).

## Нельзя

Запускать собранные страницы с боевым адресом скрипта и вводить данные «для проверки»: события и работы попадают в таблицы на Диске учителя.
