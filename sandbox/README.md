# Песочница Python в конспекте

Прототип: https://claude.ai/artifact/PVFj5L1cubGQNRNdKTBU4a
Исходник: `sandbox.html` (одна страница; библиотеки грузятся с CDN).

## Рекомендация: Skulpt

Для 8 класса (input(), turtle/Чертёжник, простые программы) лучше всего подходит **Skulpt**. Pyodide стоит держать в запасе для задач, где нужен «настоящий» Python целиком.

## Сравнение движков

| | Skulpt 1.2 | Pyodide (CPython в WASM) | Brython | MicroPython (WASM / PyScript) |
|---|---|---|---|---|
| Что это | Python → JavaScript | Настоящий CPython 3.12 | Python → JavaScript | MicroPython в WASM |
| Загрузка | ~0,6 МБ + 0,4 МБ stdlib, старт мгновенный | ~10 МБ, старт 3–10 с на школьных ПК | ~0,7 МБ + stdlib по запросу | ~0,3 МБ, быстро |
| `input()` | Асинхронный, без блокировки: поле ввода прямо в консоли страницы | По умолчанию `window.prompt()`; без него нужен воркер с SharedArrayBuffer (особые заголовки сервера) или переписывание кода в `await` | `window.prompt()` | Только через обходные пути |
| turtle | Встроен, рисует на canvas | Нет, нужны сторонние заглушки | Есть (SVG), но с ограничениями | Нет |
| Ошибки | Тип, текст и номер строки; SyntaxError бывает размытым («bad input»), поэтому на странице добавлены свои объяснения по-русски | Полный traceback как в настоящем Python, самые точные | Похожие на Python, с номером строки | Короткие, как в MicroPython |
| Перехват скриптом | Колбэки вывода и ввода, ошибка как объект с типом и строкой, лимит времени, остановка | Можно перехватить stdout/stdin и исключения | Можно, но менее удобно | Ограниченно |
| Совместимость с Python 3 | Хорошая для школьного уровня: f-строки, `//`, `**`, списки, `sorted`, `round` работают; нет многих модулей stdlib | Полная, включая numpy и т. п. | Хорошая | Подмножество |

Важная деталь: в опубликованных артефактах (и во многих LMS-iframe) `prompt()` заблокирован, поэтому вариантам с `prompt()` там нужен обходной путь, а Skulpt работает без него.

Что проверено на практике в Chromium: ввод через `input()`, f-строки, рисование turtle, NameError, TypeError (str + int), ValueError в `int()`, ZeroDivisionError, IndexError, SyntaxError (нет двоеточия, нет отступа), остановка бесконечного цикла кнопкой и лимитом времени при проверке.

## Что умеет прототип

- Редактор с подсветкой (CodeMirror), Tab = 4 пробела, Ctrl+Enter запускает, черновик сохраняется в браузере ученика.
- Раскладка: слева редактор, справа сверху вывод (с полем ввода для `input()`), снизу блок ошибок поменьше: объяснение по-русски, исходный текст ошибки Python, кнопка «Перейти к строке», строка подсвечивается в редакторе.
- Рисунок turtle открывается отдельным окном поверх страницы: лист в клетку (центр координат, клетка = 20 шагов), окно перетаскивается за заголовок, закрывается крестиком или Esc, снова открывается кнопкой «Рисунок» над выводом. На телефоне окно прижато к низу экрана.
- Задание «Сумма чисел от 1 до n»: 6 тестов (3 видимых, 3 скрытых), вердикт «засчитано / не засчитано».
- Подсказки двух видов: автоматическая по результату проверки (range(1, n), print внутри цикла, input() без int(), нет вывода, бесконечный цикл, константный ответ) и лестница из трёх подсказок по кнопке.
- События для скрипта страницы: `lessonSandbox.on('run' | 'input' | 'output' | 'error' | 'check' | 'hint', fn)` и `lessonSandbox.run(code, { inputs })`. Журнал учителя на странице собран этими подписками.

## Чего пока нет

- Журнал хранится только во вкладке ученика. Чтобы учитель видел результаты всего класса, событие `check` нужно отправлять в общее хранилище (база данных артефакта, Google-таблица, LMS).
- Задание описано прямо в коде страницы. Для курса стоит вынести задания в формат «условие + тесты + подсказки», чтобы одна песочница подключалась к любому конспекту.
